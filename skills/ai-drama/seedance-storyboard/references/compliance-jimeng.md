# 平台边界与失败处理

此文件保留原路径，避免已有索引失效。不维护“即梦敏感词大全”，不承诺审核通过。政策、账号功能与素材审核以实际入口的当前要求和错误反馈为准。

## 按任务处理边界

- 写稿不代表允许上传素材、创建付费任务或发布；用户另行授权这些操作时才交接相应工具。
- 真人肖像或声音须确认使用依据和入口要求。某入口曾限制人脸参考，不等于所有版本永久不支持真人。
- 不将健康泳装、普通恐怖、宗教符号、历史题材或虚构动作戏一律改掉。按具体内容和适用要求判断，保留创作意图。
- 不用改年龄、删敏感词等办法掩盖不可接受的内容；必要时仅调整问题部分并说明原因。
- “无水印”提示词不能保证控制平台生成标识；画面设计与导出设置分开。

## 平台拒绝或生成失败

先区分规格、绑定、模式、政策和质量问题。读取或询问实际错误，再针对原因修正；不随机删词，不以规避审核为目标。

| 问题 | 排查与修正 |
| --- | --- |
| 提交被拒 | 错误码、版本、模式、格式与数量；不先断言是敏感词 |
| 角色重复或身份串联 | 多格图是否被理解成多人，标签和人物是否一一对应，用途是否冲突 |
| 换手或动作断裂 | 起态、接触、终态是否明确；缩小一次交互范围，保留动作意图 |
| 运镜不遵循 | 路径是否矛盾、切换是否过密；先简化次要运动 |
| 台词不完整或串音 | 实测语速、说话人和轮次；留时间，必要时提出配音和后期方案 |
| 字幕错误或多余文字 | 文字需求是否冲突；允许时改后期排字，不自行删必留文案 |
| 跨段接不上 | 尾态、首态、光线、方向、道具和声音；使用真实尾帧或改剪辑点 |

每轮针对一个主要原因，说明改动与预期影响。没有成片就不声称验证了画面质量；文本审查只确认方案一致性与可执行性。
