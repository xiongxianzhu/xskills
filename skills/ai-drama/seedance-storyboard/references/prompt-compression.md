# 提示词编译与压缩

## 从导演稿到生成指令

导演稿解释目的、剪辑点与制作安排；提示词保留本次需生成的可见、可听内容。不把设计分析、验收表和后期任务整段塞入提示词。

每个生成段至少具备：

1. **任务与参数**：生成新片 / 延长 / 编辑，目标时长、画幅、风格；实际参数还须在入口设置。
2. **主体与空间**：稳定称呼、必要外观、地标与光线；有素材时写身份、服装、运镜等用途。
3. **镜头或节拍**：按顺序写机位与动作，突出关键变化与可读终态。
4. **声音与文字**：原台词归对应人物，标明时机；写环境声、动作音、配乐关系和指定画面字样。
5. **关键约束**：仅保留本段有效的身份、方向、道具与编辑范围约束。

可用短段落与 `【镜头】` 等标签组织，不强制符号协议。`（）`、`<>`、`{}` 不具有已证实的专用音乐、音效或台词解析含义；自然语言与引号即可。

## 台词与非朗读说明分离

同一个生成段内，每次计划发声只在对应的对白、旁白或内心独白字段写一次原文；多人时标明说话人。引号内仅放需要念出的字句，语气、停顿与动作写在字段外。不要再附一份重复的完整台词汇总供模型同时生成。

- 动作与声音说明用“句首、后半句、说完后”或明确时段定位，避免用“说到某词时”再逐字引用台词。情绪总说明只写声线、转折和停顿，不再次复述各句。若要求精确对词动作，让目标词仅保留在对白中，在动作栏用该词所在的分句或时段关联。
- 若用户确实要求重复说话、回声或跨镜接句，保留相应次数、声源与承接时机；跨镜后从下一段原文接起，不重新念上一镜内容。不因去重擅改锁定台词。
- 字幕、招牌等画面文字单列，是否朗读按用户要求；不要以删除引号、字幕或正常重复词的方式消除歧义。无对白任务不套用台词模板。
- 有发声边界歧义时，可在生成段中补一句“仅朗读明确标注的对白、旁白或内心独白，其余为非朗读说明”。这是自然语言约束，不能保证生成模型严格遵循。

例如，避免把“说到‘闭眼’时缓缓眨眼”与对白混写。可改为：

```text
画面：正面近景，固定镜头。女子说话过程中自然缓慢眨眼一次，随后重新注视镜头。
对白（女子）：“不然，为何一闭眼……”
声音：语气疑惑，句尾短暂停顿；古琴轻铺，音量低于人声。
```

下一镜可继续接句，但不在动作栏、声音栏或全局表演说明中重复引用前句。此写法减少文本歧义，不要求所有任务都使用眨眼、分句或相同景别。

用户反馈多念、串词时，先核对对白原文及说明中的重复片段；有实际提交稿、平台改写稿或成片时再对照。未听到成片、未排除平台改写和生成波动时，只指出疑似歧义，不断言某个引号或词必然造成额外发声。先修受影响文本，再核对生成结果，不声称改稿已证明音频问题解决。

## 时间写法

可写“0–3 秒建立空间；3–7 秒动作；7–10 秒反应”，或用“起初、随即、最后”。后者仍须在导演稿核算时长。卡点写目标时机，并核对成片。

分段使用局部时间，第二段也从 `0 秒` 起，不直接写全片的 `15–19 秒` 让模型误解本段长度。

## 压缩顺序

先明确预算针对每个提示词块还是整份交付。默认每段 2000 字符是可调整的制作预算；入口或用户要求更严格时从严。

1. 删无信息修饰、同义画质词和解释创作原因的句子。
2. 相同外观、风格、光影、环境音集中写一次。
3. 删无关背景和次要音效，不删建立方向所需地标。
4. 减次要镜头或将连续动作合为一镜；同步修改导演稿，不能只改提示词。
5. 仍超限则压缩交付格式或建议分段；锁定台词、字幕、关键事件、参考绑定不可擅删。

独立生成段允许必要重复，不能为减重复改成“人物同上”“延续前文”，因为模型未必接收前文。

## 保真对照

| 要素 | 提示词保留 | 可移至制作说明 |
| --- | --- | --- |
| 人物与素材 | 身份、服装、标签及用途 | 待准备素材的采购或裁切计划 |
| 动作 | 主体、方向、交互、起态与终态 | 选动作的分析 |
| 运镜 | 路径、关键景别与焦点 | 无关设备清单 |
| 台词与字幕 | 原文、说话人、时机 | 精确字形和时间的后期校对 |
| 声音 | 声源与动作的同步关系、台词可懂 | 音轨命名、混音导出流程 |
| 连续性 | 站位、持物、光线、衔接状态 | 其他段落的完整分镜 |

## 字符计数

按 Unicode 字符数，包含标点、空格、换行和块内所有文字，包括首句。统一换行为 `\n`，去掉代码块外壳与块首尾空白后用 `len(text)` 统计。全文预算对实际交付全文统计，不用提示词块长度之和替代。

本地有稿件时可用 Python；不为简单对话强制创建文件。没有工具时保守压缩并标为估算，不写未经计算的精确字数。平台计数口径不同时，以输入框为准并留余量。

## 字幕与否定约束

默认可写“画面无额外字幕”，但指定字幕、招牌、品牌名或喊话字幕须保留。不在同段既要求“画面无文字”又要求产品文案。

优先正向描述，必要时可用“不改变原运镜”等简短否定。不存在一律删除“不要、禁止”等词的规则，正常台词中的否定词不能判为质量失败。

生成内文字与后期排字分开：用户要求生成文字则忠实写入并说明检查需要；允许后期处理时才将精确标题留给剪辑，不假称已生成正确字形。
