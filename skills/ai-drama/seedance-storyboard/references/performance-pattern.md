# 成功案例与表演型提示词

## 证据与适用范围

来源：用户提供《和我的恋爱规则》15 秒、16:9、精细 3D 国漫 CG 提示词，并反馈一次生成即可成片、没有废片。此处记录用户反馈及可复用写法，未独立观看该案例成片，未记录其模型子版本、种子或生成设置；不能据此承诺其他题材一次成功。

适用：单人对镜口播、恋人视角互动、角色宣言、人物展示中的短对白。提炼结构和控制变量的方法，不默认继承粉色服装、女性角色、恋爱题材、15 秒或五镜头。

## 从案例提炼的写法

| 案例特点 | 可复用原则 | 应避免的误用 |
| --- | --- | --- |
| 唯一人物参考，并说明多视角仍是同一角色 | 明确身份来源、稳定特征、画面人数与完整场景 | 没有附件却写“以附件为准”；把人设拼板生成多人 |
| 明确镜头代表恋人视角，人物看镜头说话 | 交代受话对象、视线目标和摄影机的叙事身份 | 所有剧情都要求角色直视镜头 |
| 同一闺房、光线方向稳定 | 全局设定集中一次，靠表演和景别改变信息 | 为追求视觉变化每镜换房间、天气和光色 |
| 每镜有清晰时段，画面、对白、声音分行 | 一眼可读的时间—行为—台词对应关系 | 把复杂肢体、光影、音效混成一条密集长句 |
| 歪头、挑眉、点掌心等动作服务具体语句 | 每镜一个主要表演意图，搭配少量辅助动作 | 同时安排转身、走动、摆手、换表情与长对白 |
| 甜笑 → 认真 → 恢复甜笑 → 期待 → 温柔强调 | 通过情绪差异推进内容，给前后表情过渡 | 全程同一笑脸，或每个词都指定一个表情 |
| 固定镜头与缓推交替，景别围绕中近景变化 | 表演承载信息时减少摄影机竞争 | 把固定机位规定为所有题材唯一正确运镜 |
| 声音随语句转折，音乐低于人声 | 明确主声源、停顿和情绪落点 | 每句都堆音效，掩盖对白 |
| 结尾停留半秒 | 给最后表情与语句留下完成空间 | 台词尚未说完就强行切黑 |

以上是从脚本结构推导的制作方法，不是已证明的成功因果排序。

## 默认组织方式

人物口播优先采用如下模块；无对白、无参考图或已有用户格式时删改相应模块，不强行补齐：

1. **视频规格**：时长、比例、视觉风格、主题、情绪反差及镜头视角。
2. **角色参考**：实际提供的身份参考与少量识别特征；多人时分别绑定；多视角图明确同一人。指定参考与文字发生冲突时先确定哪项优先。
3. **场景**：一个清晰空间、关键陈设、主光方向和背景层次。
4. **分镜与对白**：每镜单列编号和时间，依次写景别 / 运镜、主要动作 / 表情，再单列“对白：”与“声音：”。
5. **表演与声音**：声线、语言、情绪曲线、口型目标、停顿、人声与配乐层次。
6. **画面约束**：本次真实需要的身份、材质、人数和拼板约束；不堆叠无关禁词。

无字幕任务可保留开头“画面无任何字幕。”；用户需要文字时按需求替换。此句不是必须使用的模型口令。

## 案例中的五个节拍

| 时间 | 表演意图 | 原对白 | 摄影与声音作用 |
| --- | --- | --- | --- |
| 0–3 秒 | 甜笑宣布规则，抬一根食指 | 和我在一起，要守规矩哦。 | 中景缓推建立对话，拨弦起 |
| 3–5 秒 | 笑容收住，前倾与挑眉强调 | 不许装作没听见。 | 近景固定，音乐暂停、低鼓强调 |
| 5–8 秒 | 恢复笑容，指尖点掌心列约定 | 第一，想我就要告诉我。 | 中近景固定，拨弦恢复 |
| 8–11 秒 | 点脸颊，期待回应 | 第二，出门前，要亲一下。 | 略偏侧近景缓推，柔软铃音 |
| 11–15 秒 | 认真强调后转甜笑，眨眼收尾 | 最后，心里只能有我。记住啦？ | 正面近景固定，语气放轻并留尾停顿 |

保留原稿作为用户成功案例，不按通用语速估算擅自改写它。新任务仍需估读或试音：尤其 3 秒内的长句与 2 秒内的停顿、表情要共同计时；一次成功不表示任意声线都能自然说完相同字数。

## 迁移到双人动作戏

继承模块清楚、身份有来源、场景稳定、每镜重点单一；不直接继承小动作、固定站位或五句对白。

- 双人戏分别建立角色身份与武器特征。只有文字时说明外貌属于设计目标，不能用“保持一致”替代具体视觉参考。
- 每镜围绕一组主导攻防，如“进攻—格挡—分开”，允许动作内部自然衔接；精确描述关键接触与结果，不逐帧规定所有关节。
- 用接触后的卸力、退步、重建距离组织下一拍，不连续多秒锁在交叉剑姿态，除非剧情确需角力。
- “保持轴线”控制观众对方向的理解；不等于把人物钉死在画面左右。换位要有可见路径和新的空间交代。
- 将场景、风格和身份稳定，给动作与摄影保留必要自由；不同时增加贴身遮挡、速度变化、调焦和密集切镜。

若平台会重写提示词，对比实际提交文本与原稿，记录新增限制、风格变化和模型子版本。判断失败原因时区分原稿、平台改写、素材与生成波动；仅看提示词不能定位视频中的具体穿帮帧。
