# 素材绑定与连续性

## 参考清单

只为已有、可访问或由用户明确给出用途的素材建立引用。区分“实际看过”和“仅有用户描述”；视频只看过若干帧时，不声称已听过声音或掌握完整动作。

| 标签示例 | 控制项 | 必须澄清的边界 |
| --- | --- | --- |
| @图片1 | 主角脸型、发型、配饰 | 只锁身份还是同时锁服装；不继承无关背景 |
| @图片2 | 服装轮廓与材质 | 与身份图冲突时由服装图控制哪几项 |
| @图片3 | 场景地标、光源 | 不把图中路人带入新片，不强制所有镜头同一构图 |
| @视频1 | 动作节奏 / 摄影机路径 | 写清时间区间与用途，不擅自迁移人物外貌或剧情 |
| @音频1 | 音乐节拍 / 台词 / 音色 | 三者分别确认，不能默认同时控制全部 |

上表是命名示例，不要求用户准备五份素材。文字生成无需参考清单；只有一张人设图就从一张图写稿。

三视图和多格图：说明各视角为同一角色，最终画面只有一位；建议选用单一正面或侧面视图作为身份参考，必要时提出裁切方案。未实际裁切就保留原标签，不编出新文件。

## 最小连续性记录

只记会影响镜头的项目，通常每类一两行足够：

- **角色**：稳定称呼、可见身份特征、发型、服装、左右不对称配饰、体型和道具；新增设计与素材事实分开。
- **场景**：入口、出口、地标、人物路径、机位所在轴线一侧；多场景分别记录。
- **视觉**：时间、天气、主光方向、主辅色、材质、运动风格。
- **声音**：说话人、语言、音色与情绪、持续环境声与音乐动机；未指定参考时写设计目标而非声纹复制结果。
- **状态**：谁拿着什么、哪只手、衣物干湿或破损、门开合、物体位置、运动方向与速度。

人物自身左 / 右与画面左 / 右分开写，不在机位不明时将两者等同。背面、镜面、过肩反打时重新核对。

## 轴线、视线与动作接点

- 两人互动先建立空间，例如“A 在画面左看右，B 在画面右看左，摄影机在连线南侧”。反打后核对目光，不只写“保持一致”。
- 行进保持屏幕方向；转向须有可见转弯、正面中性镜头或重新建立空间的镜头。
- 可有意越轴，但写出越轴过程或重建关系，不把失误包装成转场。
- 动作匹配切：前镜开始抬右手，后镜接右手已抬到的合理阶段；不瞬间换手、复位或重新拔刀。
- 连续时间保持主光与天气；蒙太奇、时间跳跃、闪回明确变化依据。
- 道具出现、消失、损坏、转手有原因；碰撞后写速度、重心和衣物的延续反应。

## 分段衔接

| 段落 | 终态 → 下一段起态 | 接法 |
| --- | --- | --- |
| A → B | 主角在石柱左侧，右手持刀，左脚落地，面向画面右 | 下一段从左脚承重开始接行进，用柱体遮挡切 |
| B → C | 钥匙已交到对方左手，门仍关闭 | 下一段从对方抬左手开门开始，用钥匙近景切 |

独立生成时，每段重述必要的身份、场景、光线、声音与起态，不能假设模型记得上一请求。上一段尾帧或视频属于生成后才可获得的衔接素材；尚未获得时提供文字起态方案，不伪造已上传引用。

区分全片成片时间与段内局部时间。例如成片 15–20 秒对应第二段 0–5 秒，分镜保留全局时间，提示词用局部时间。

## 编辑与延长

- **局部修改**：明确唯一修改目标、源视频区间和保留项。只改服装颜色时，身份、表演、场景、动作、运镜、原声与时长均继承源片，不附送新镜头。
- **向后延长**：读取终态与声音，写新增时长、新动作；回顾原片只留衔接必要信息，不要求重演整段。
- **仅参考运镜**：明确生成新片，仅借用路径与速度曲线，不写成修改原视频。
- 看不到原片但用户给出终态描述时，可依描述写条件化稿；连终态也没有时先索取，不虚构。
