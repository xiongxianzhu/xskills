# 导演调度与时间预算

## 先决定观众要看懂什么

| 目的 | 组织方法 | 失败信号 |
| --- | --- | --- |
| 剧情 | 用行为呈现目标，安排阻力与可见转折，给结果或悬念落点 | 华丽镜头很多，人物行为却不导致变化 |
| 人物展示 | 由轮廓、标志细节、动作到表情建立记忆点 | 堆叠局部特写而无统一气质，或擅自扩写剧情 |
| 动作 | 建空间 → 接近 → 接触 / 躲闪 → 反作用 → 新站位 | 瞬移、发力无支点、受力无反馈、顺序不清 |
| 广告 | 一个主要卖点，对应可见使用结果与产品记忆镜头 | 堆卖点，产品大小、形状跨镜漂移 |
| 环境 / ASMR | 一个空间揭示或一组可辨声源，留声音发生、衰减的时间 | 凭空添加台词，配乐盖过关键声源 |

不机械套用三幕、黄金三秒、固定高潮或每镜两秒。短片可以只有一次回眸、一次交接或一个空间揭示。

## 时间预算

先分配台词与不可删动作，再安排建立、反应、停顿和结尾。下表只是起稿参考，不是模型限制：

| 总时长 | 常见组织 | 调整依据 |
| --- | --- | --- |
| 4–6 秒 | 一个完整动作，一镜或两个互补镜头 | 特写表演需停顿，不能塞完整追逐和反转 |
| 7–10 秒 | 2–4 镜，或一个有起落的长镜头 | 主体数量、台词与交互复杂度 |
| 11–15 秒 | 3–6 镜，或少镜头持续表演 | 不为凑镜数切碎动作链 |
| 更长作品 | 按叙事单元分生成段，各段镜数独立确定 | 模型时长、场景变化、对白和连续性成本 |

成片时间从 0 到目标时长，区间首尾相接，无未交代空隙或重叠。声音可跨切点延续，画面时间仍只算一次。区别“人物姿态收住半秒”与导出定格帧。

每段实际使用时长之和等于成片时长。生成素材可更长以留剪辑余量，但仍须满足目标模式。成片短于平台最小时长时，计划生成合法长度再截取，不谎称能直接生成任意小数秒。

## 对白与声音预算

普通中文口语先按每秒约 3–4 字估算，不计标点，再为停顿、呼吸、口型起落和反应留时间。这是制作估算；方言、情绪、数字读法和外语需按实际读法或音频测时。

16 字台词通常先预留约 4–5.5 秒，再加表演停顿；不能要求人物在 2 秒镜头里高速念完。逐字保留时可提出延长、减少同期动作或调整覆盖镜头。旁白跨镜能重分配时间，但不能解决整片时间不足。

每句标明说话人、原句、语言、语气、开始时机和是否露脸口型。画内对白、画外角色声（OS）、解说旁白（VO）不同，不擅自互换。多人对白明确轮次，避免无意抢话。

用事件触发音画：脚掌着地时水声、门锁弹开时咔哒声、揭示时音乐进入。没有音频可测就不编造 BPM、拍点或采样级同步。配乐让对白可懂，精确同步交后期验收。

## 摄影机与构图

- 切镜或运动服务揭示信息、跟随动作、改变力量关系或情绪；固定机位也是完整选择。
- 区分主体移动、摄影机位移、变焦和焦点转移。跟拍不意味着主体在原地跑步。
- 默认一个主导运镜；组合时写先后路径，例如“先侧跟三步，人物停下后绕至正前方收住”。避免同时推近、拉远、绕圈和急摇。
- 一镜到底可变景别和调焦，但路径连续可行；跨段遮挡拼接要说明是后期模拟长镜头。
- 竖屏为发顶、鞋、武器和肢体留活动空间；横屏利用人物关系与运动方向。UI 安全区按投放规范，不给所有平台同一像素边距。
- 焦段、快门感和景深是可见效果目标，不是未经验证的模型参数；高速动作不默认全程浅景深或慢放。

## 动作戏的可执行性

关键交互写为“准备 → 发力 → 轨迹 → 接触 / 避让 → 回收或落地”。只精确描述影响结果的肢体，不为每根手指编复杂运动。

示例：A 右脚蹬地向画面右突进，右手横挥木刀；B 后撤半步，以左侧护具挡住刀路；接触时 B 上身向后让力；A 收刀停在画面左，B 落稳在右。冲击音随接触发生，速度变化集中在接触瞬间。

摄影机速度匹配人物速度。跳跃有支点和落点，倒地有失衡原因；光效跟随武器轨迹，不遮掉关键接触。保留冲击力与可读性，不把动作全删成“身影交错”。

## 单段还是分段

- 同场景连续表演、道具交接、对白在能力范围内时，优先同段。
- 场景转换、自然停顿、视线揭示、遮挡、动作匹配点适合分段；避免优先截在腾空中点或手部交接中间。
- 2.0 的 30 秒动作短片可分 15 + 15 秒，在第一段落地后的新站位接反击；不是把同一段 30 秒提示词从中间剪开。
- 无自然接点时，明确所需尾帧、状态记录或后期接点，不保证独立生成天然无缝。
