# 输出模板与验收

按用户要求选择交付形态；完整导演稿不是每次必需的固定流程。

## 完整版

1. **参数与假设**：版本 / 入口、目的、成片总时长、画幅、风格、声音、文字和预算；只解释重要默认项。
2. **素材与连续性**：有素材才列映射；多人、多镜头或分段时记录必要外观、站位、方向、持物与光线。
3. **分镜**：简单镜头用表格；复杂动作与对白逐镜分块，信息一致即可。
4. **生成段**：每段成片区间与生成时长，每段一个 `text` 块；有裁切或余量时标明使用时长。
5. **交接**：仅列必要素材准备、接点、精确文字 / 音画校对及未核实能力。

示意分镜表：

| 镜号 / 时间 | 目的 | 画面与动作 | 摄影机 / 光影 | 声音 / 切点 |
| --- | --- | --- | --- | --- |
| S01 · 0–3 秒 | 建交接关系 | A 左 B 右，A 右手握钥匙，两人停在门前 | 双人中景，人物连线同侧；右后暖灯 | 走廊低鸣，A 抬手时切 |
| S02 · 3–6 秒 | 完成交接 | A 右手将钥匙放入 B 张开的左手，B 握稳 | 同侧近景，焦点跟随钥匙，灯光延续 | 金属轻响，握稳后结束 |

此表展示结构，不要求所有任务拍递钥匙或用两个镜头。

## 精简版

只要提示词或全文限字时，省去重复表格与分析，直接给独立提示词。重要假设、绑定和限制合并为短说明；多段每段一块。

全文限字覆盖整份回复，不再输出等长解释稿。仅在用户要求或精确预算需要时显示计数，不伪造统计值。

## 局部修改版

一句话说明改动范围，给出受影响的完整提示词块，其余块不重复。时长变化同步调整后续区间；道具、站位变化同步修正相关衔接。用户要整合版再给整稿。

## 审核顺序

先修不可交付的问题，再做审美优化：

| 检查 | 通过标准 |
| --- | --- |
| 需求保真 | 时长、画幅、题材、角色、原台词、字幕和修改范围保留；冲突已说明 |
| 时间与模式 | 时间闭合，单段长度与输入符合模式，动作台词有完成时间 |
| 发声边界 | 按时间提取对白、旁白与内心独白，核对说话人、原文、顺序和预期次数；动作、配乐及语气说明不重复引用待朗读片段，指定字幕和有意重复保留 |
| 动作可读 | 起态、路径、交互和终态可理解，镜头目的明确 |
| 连续性 | 视线、轴线、方向、持物、道具与主光衔接合理 |
| 参考正确 | 不虚构已看素材、上传状态或标签，用途与优先级明确 |
| 提示词可用 | 每段独立可复制，局部时间从 0 起，与导演稿一致，字数统计范围正确 |
| 质感与节奏 | 运镜有动机、信息有先后、表演留空间、声音跟随事件 |

可修问题先修，不把清单原样附在每次回复后。未生成成片时只报告文本与计划已校对，不声称视频效果已验证。

## 维护者行为评估

[评估用例](../evals/evals.json) 包含真实任务与人工判断标准。[评估脚本](../scripts/grade_evals.py) 只检查字符预算、提示词存在、必留原文和未声明引用，不能代替导演质量评审。

在技能目录运行 `python scripts/grade_evals.py output.md --eval bamboo-portrait-9x16`；`--eval` 对应用例的 `name`。脚本打印 JSON，失败返回非零，另列未自动判断的 criteria，不伪报它们已通过。
