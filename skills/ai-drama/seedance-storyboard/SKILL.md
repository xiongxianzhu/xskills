# Seedance 2.0+ 导演分镜

把创意转成能审阅、能生成、能剪辑的分镜。以中文交付；用户指定语言、格式、字数或只要提示词时，以用户要求为准。默认产出文本，不上传素材、不调用视频生成服务。

“2.0+”表示以 2.0 为基线、按实际版本适配，不是一个已核实的模型名称。保持导演决策与平台参数分离。

## 1. 确定任务与不可变项

提取：版本与入口、创作目的、总成片时长、画幅、风格、人物与场景、关键事件、必留台词、声音、字幕、现有素材和字数预算。只在缺口会实质改变结果且无法推断时集中提问；其余采用默认值并用一句话说明。

| 缺省项 | 处理 |
| --- | --- |
| 版本或平台不明 | 按 2.0 的保守制作方案写稿，标注入口未核实；不直接套用新版本能力 |
| 时长、画幅 | 沿用上下文；仍无信息时按 10 秒、16:9，不覆盖明确的竖屏要求 |
| 字数 | 每个生成段提示词默认以 2000 字符为交付预算，不凑满；这不是官方通用上限 |
| 字幕、对白 | 默认不额外添加画面文字和对白；有指定台词、字幕、品牌字样时原样保留 |
| 风格 | 从剧情或可查看的素材推断；不把所有题材默认做成国漫或角色展示 |
| 素材缺失或不可查看 | 如实说明，仅依据用户描述写作；关键身份或续写起点不明时索取缺失信息，继续独立部分 |

识别任务分支：

- **剧情**：明确人物目标、阻力、可见转折和结果；删掉不服务这一变化的镜头。
- **角色展示 / PV**：围绕识别度、服装、身形、武器或气质安排揭示顺序；不擅加反派、追杀或身世剧情。
- **人物口播 / 对镜互动**：读取 [成功案例与表演型提示词](references/performance-pattern.md)，优先用角色参考、固定场景、清晰时间段和逐镜对白组织。每镜一个主要表演意图，保留情绪转折与反应时间。
- **动作戏**：保留速度与冲击力，写清接近、出招、接触或闪避、反应、落点；不为稳定性一律改成慢动作。
- **广告 / 环境 / ASMR**：围绕核心卖点、空间变化或声源组织；静物和风景无需强加人物与对白。
- **续写 / 编辑**：先区分新生成、参考迁移、延长与局部修改。编辑只改指定项；延长从可确认的终态开始。

普通不限定模型的分镜、静态故事板、整首歌 MV 可分别转向 industrial-storyboard、director-storyboard-sheet、music-mv-storyboard；不读取或依赖这些技能的文件。

## 2. 核实能力并绑定素材

涉及单次时长、输入数量、模式、分辨率、引用语法或后续版本时，读取 [版本与平台适配](references/seedance-specs.md)。任务需要最新能力或接近限制时核实当前官方文档与实际入口；不能联网时使用已注明日期的基线，不声称已核验最新规则。

有参考图、视频、音频或首尾帧时，读取 [素材绑定与连续性](references/continuity-and-references.md)：

1. 先查看可访问的素材，再建立「文件或平台标签 → 对象 → 参考用途 → 不继承内容」映射。
2. 区分角色身份、服装、场景、构图、动作、运镜、音色和音乐节奏；明确冲突时哪份素材控制哪一项。
3. 仅引用实际存在或用户明确给定的素材。待补拍、待裁切、待生成的图单列为制作建议，不冒充已上传标签。
4. 三视图或多格图中的同一角色仍是一个主体；说明采用哪个视图、是否先裁切，不让多个视角变成多个人。
5. `@图片1` 等是素材绑定的可读表示，实际输入前用入口选择器或引用规则绑定；不把文本标签当作已上传素材或通用 API 参数。

## 3. 先设计节拍，再分镜与分段

读取 [导演调度与时间预算](references/directing-and-timing.md)。先安排观众依次看到什么、何时理解和何处发生变化，再选景别与运镜。

- **镜头**是剪辑单位；**节拍**是一镜内部的动作变化；**生成段**是一次模型请求的交付单位。三者不强制一一对应。
- 给分镜明确的成片时间区间和时长，总和等于目标成片时长。提示词可用简洁时间区间或顺序节拍；它们是节奏目标，不承诺模型逐帧执行。
- 镜头数量由内容决定。一镜到底只分动作节拍，不能暗含硬切、换机位或不可能的瞬间跳位。
- 先预算不可删台词和必要动作，再分配停顿、转场与结尾；超载时解释冲突，优先减次要镜头或提出延时方案，不暗改原台词。
- 超过已核实的单次限制时拆成独立生成段。记录成片区间、单次生成时长、实际使用时长和衔接状态；跨段不用“同上”代替角色与环境约束。
- 转场余量是额外生成素材，不凭空计入成片总时长；若余量使单段超限，重新分配或使用硬切。

## 4. 写能拍出来的镜头

每镜按需包含下列信息，不要求把所有字段塞成一条长句：

| 要素 | 写作要求 |
| --- | --- |
| 目的与时间 | 一条主要信息或情绪变化；成片起止与时长 |
| 构图与机位 | 景别、视角高度、主体位置、必要的焦点变化；焦段仅在透视效果有意义时提供 |
| 主体与动作 | 谁在何处、朝哪儿、用哪只手、如何作用于对象，写出可见起态与终态 |
| 表演 | 目光、呼吸、停顿、姿态等可见信号；从情境选择，不堆砌互相冲突的微表情 |
| 摄影机路径 | 起点、路径、终点和速度变化；默认一个主导运动，可按动机连续组合，不能同时前推又后拉 |
| 场景与光影 | 地标、主光方向、色温和材质响应；继承全片设定，仅写本镜变化 |
| 声音 | 说话人、原句、语言和时机；环境音、动作音、音乐各司其职，标明必要的音画触发关系 |
| 切点与衔接 | 用什么动作、视线、遮挡或声音承接下一镜；追踪站位、道具、朝向和动作阶段 |

以可见内容落实“电影感”：前景遮挡形成层次、主光塑形、景别变化产生信息差、表演留有停顿。不靠“8K、UE5、HDR、大片、史诗”堆叠代替调度，也不把这些词当输出规格保证。

## 5. 编译为可独立复制的提示词

读取 [提示词编译与压缩](references/prompt-compression.md)。每个生成段输出一个独立 `text` 代码块，包含本段所需的主体、环境、节拍、声音和引用用途；保持与分镜的动作顺序、台词、左右位置、首尾状态一致。

- 全局外观与光影集中写一次；镜头内优先写动作和变化。
- 人物口播优先使用「视频规格 → 角色参考 → 场景 → 分镜与对白 → 表演与声音 → 画面约束」的分层结构；将每镜的画面、对白、声音分行，避免长段落中混写全部指令。用户只需生成稿时直接交付一个完整代码块。
- 待朗读原文集中在对应的对白、旁白或内心独白字段；动作、语气和配乐说明用句首、句尾或时间定位，不再引用台词片段。按实际发声次数编排，保留剧情需要的重复与跨镜接句；详见 [台词与非朗读说明分离](references/prompt-compression.md#台词与非朗读说明分离)。
- 有素材时写清用途，不让运镜参考覆盖角色身份，也不让角色参考强行锁定所有镜头构图。
- 用户规定“全文不超过 N 字”时，预算涵盖标题、说明、表格和所有提示词；不能只统计一个代码块。
- 字符计数以工具实测为准；无工具时不要编造精确字数。字幕与台词不因压缩擅改。
- 首尾帧模式写清两端之间的可达路径；参考模式不冒充首尾帧约束。编辑说明源视频、修改对象和不变量；续写说明衔接状态与新增内容。

## 6. 检查并交付

标准交付：**参数与重要假设 → 素材映射（有素材才给）→ 分镜 → 分段提示词 → 必要的衔接或后期说明**。按 [输出模板与验收](references/output-and-review.md) 选择完整版、精简版或局部修改版。镜头多时用表格，复杂时逐镜分块，避免过宽表格。

交付前检查：

- 时长闭合、生成段符合已核实模式，台词和复杂动作有实际完成空间。
- 主体、持物手、方向、视线、光线、道具状态与切点前后对应。
- 素材标签有来源，各提示词块可独立使用，字数统计涵盖用户实际限定范围。
- 保留指定版本、风格、字幕、对白、角色数量和修改范围；不无依据地禁止时间码或组合运镜。
- 按说话人和时间顺序核对待朗读内容，检查漏句、额外重复及混入台词的动作说明；字幕、配乐和表演说明不被误作发声内容。
- 只说明真实影响结果的限制；不保证锁脸、精准口型、逐帧时间、文字正确或平台审核一定成功。

涉及平台拒绝、真人肖像、声音授权或危险内容时，按需读取 [平台边界与失败处理](references/compliance-jimeng.md)。普通虚构动作戏不因“打斗”一词自动删掉过程，不建立未经来源支持的敏感词黑名单。

需要可复制样例时读取 [完整示例](references/examples.md)，按当前任务改写，不照搬镜头数量与题材。用户只改一项时，保留其余设定，仅重写受影响的镜头、段落与必要衔接。

默认在对话中交付 Markdown；用户要求文件时按指定目录保存，未指定时用当前工作区的 `分镜脚本-主题.md`，遵循宿主环境的保存规则，不覆盖同名文件。
