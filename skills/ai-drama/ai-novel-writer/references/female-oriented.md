# 女频创作策略

## 核心体验

女频追读通常由人物关系、情感选择、自我价值和生活处境共同驱动。甜、虐、爽和成长需要改变人物之后的行为、边界或权力关系，不能只停留在情绪形容。

常见承诺包括：

- 在不平等关系中重新获得选择权
- 两个有真实阻碍的人逐步建立信任
- 经历失去后完成成长与重建
- 在家庭、事业和亲密关系中确认自我价值
- 共同面对身份、时代或责任带来的压力

## 主角与情绪引擎

明确女主角的：

- 当前处境：她受到什么现实限制。
- 外部目标：她现在需要完成什么。
- 内部需要：她真正缺少什么。
- 错误认知：她对自己、他人或关系错误相信什么。
- 筹码：她能影响局势的能力、资源或关系。
- 底线：什么事情不可妥协。
- 选择权：她能决定什么，又被谁夺走了什么决定权。
- 成长选择：她最终需要主动改变什么。

读者站位来自具体处境、努力和选择，不只来自主角被伤害。

## 关系双方

感情对象和重要配角分别明确：

- 自己的现实目标
- 能够交换或威胁的筹码
- 不愿退让的底线
- 对主角的错误判断
- 主角不在场时仍会推进的行动

重要人物不能只作为主角的奖励、阻碍、救援者或制造误会的工具。

## 阶段循环

```text
关系或处境失衡
→ 人物因现实目标发生互动
→ 暴露新的立场、能力或脆弱点
→ 信任、边界或权力发生变化
→ 人物做出有代价的选择
→ 产生甜、虐、爽或成长兑现
→ 新状态制造下一阶段问题
```

每次重要对话至少改变一项：

- 信息
- 信任
- 边界
- 权力
- 承诺
- 行动方向

## 前三章要求

- 第一章建立处境失衡、现实目标和第一次主动选择。
- 第二章通过具体事件迫使重要人物互动，暴露新侧面或筹码。
- 第三章完成一次可感的边界、权力、信任或自我选择变化。
- 三章内证明人物关系能够持续产生不同事件，而非只靠误会拖延。

## 情绪兑现

先写触发情绪的具体事件，再写反应与选择。有效兑现包括：

- 主角明确拒绝不平等条件
- 对方为承诺付出可观察代价
- 隐瞒的信息改变关系判断
- 主角的能力或劳动得到实际尊重
- 一次信任建立后改变双方行动
- 虐点迫使人物修正认知或边界

用动作、停顿、距离、物件和选择承载情绪。心理描写可以存在，但不能重复已经通过行动表达的内容。

## 误会与伤害

- 误会应来自身份、利益、证据或真实风险，不长期依赖拒绝正常沟通。
- 伤害必须产生后果，修复需要行动、时间和代价。
- 霸凌、控制和伤害不能被无条件浪漫化。
- 虐点需要推动认知或关系变化，不重复伤害只为延长篇幅。

## 避免

- 所有配角只围绕恋爱线存在
- 只有内心独白，没有可见行动
- 人物突然改变立场，只为制造甜点或虐点
- 用降智误会代替利益和价值冲突
- 用持续受害代替人物成长
- 让强势角色的资源自动解决女主全部问题
