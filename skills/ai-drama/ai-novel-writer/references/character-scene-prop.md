# 人物、场景与物件设定

## 目标

把人物特征、场景规则和物件状态变成能够进入冲突、影响选择并保持连续性的小说事实。设定不是百科资料；只记录后续写作会使用、验证或改变的内容。

`01_角色设定.md`、`06_场景设定.md` 和 `07_道具装备设定.md` 是小说事实源。`漫剧改编/00_视觉资产总表.md` 从它们提取视觉信息，不反向修改小说设定。

## 角色分层

根据人物对因果和读者期待的影响决定填写深度：

- **核心人物**：主角、主要对手、关键关系人物，以及对终局拥有独立决定权的人物。完整记录叙事人格、可观察特征、视觉身份和人物弧线。
- **重要配角**：记录目标、筹码、边界、缺陷、独立行动、语言行为、主要外貌、常用服装、标志性元素和四种常用表情。
- **功能性角色**：只记录姓名或称谓、社会身份、剧情功能和一个稳定辨识点。一次性路人不强制建卡。

不要因为角色有姓名就填写完整角色卡，也不要把真正影响主线的配角压缩成一句剧情功能。

## 核心人物设定

### 基本身份

记录：

- `id`：稳定的小写英文标识，用于跨文件引用。
- `name`：中文姓名。
- `name_en`：可选英文名，仅在生产需要时记录。
- `age`：具体年龄或清楚的年龄段。
- `gender`：性别。
- `role_type`：主角、主要配角、对手或其他准确类型。
- 身份、职业、社会位置、阵营和公开身份与真实身份的差异。

### 叙事人格

记录：

- 外部欲望、内部需要和当前目标。
- 读者为何愿意理解、支持或持续观察该人物。
- 能力、资源、筹码和能力边界。
- 缺陷、错误认知、底线和越过底线的真实代价。
- 最害怕失去什么、最不愿承认什么、最容易被什么激怒或打动。
- 价值发生冲突时的排序，例如亲人、尊严、秩序、自由和利益谁优先。
- 压力下的决策偏向、失败后的反应和真正放松时的状态。
- 面对上位者、同伴、弱者、敌人和亲密对象时不同的关系模式。
- 主角不在场时仍会推进的独立行动。
- 初始状态、关键变化和最终状态。

### 可观察特征

人物特征必须能被读者看见，而不是只用形容词宣布。记录：

- 说话节奏、句子长短、惯用词、称呼习惯和不会使用的表达。
- 习惯动作、站姿、步态、视线和下意识反应。
- 生气、恐惧、撒谎、犹豫、放松和作出重大决定时的不同表现。
- 做选择时最先关注的信息、经常忽略的信息和常用解决方式。
- 首次出场必须展示的特征，以及首次登场后的三章内需要自然证明的核心特征。
- 不能与其他核心人物重复的语言、动作或判断方式。

至少为每名核心人物设计三个特征证据，使用以下逻辑：

```text
触发条件 → 可见行为或语言 → 影响选择或关系 → 产生具体后果
```

例如，不要只写“谨慎”。说明他面对陌生证据时会先检查什么、如何表达怀疑、因此避开什么风险，又会错过什么机会。

特征证据不等于固定口头禅或每章重复同一动作。同一人格应在不同压力下产生有变化但可追溯的行为。

### 固定视觉身份

记录以下视觉字段：

- `body_ratio`：身材比例、体型、身高感和体态。
- `appearance`：面部轮廓、眉眼、鼻唇、发型、发色、肤色、体貌和辨识性标记。
- `clothing`：按日常、工作、正式、战斗或特殊剧情场景分类的服装，说明颜色、剪裁和材质。
- `accessories`：长期佩戴的眼镜、发饰、首饰、护具或身份配件。
- `signature_element`：贯穿始终、不可随意替换的视觉符号。
- 姿态、步态和远景中仍容易识别的轮廓。
- `mood_tags`：中文气质描述；需要图像生产时可附英文关键词。

外貌描述优先选择两至四个稳定辨识点，不堆砌互相竞争的五官形容。服装变化需要符合身份、季节、场景和经济条件。

### 表情库

核心人物记录八种基础表情：

1. 平静
2. 喜悦
3. 愤怒
4. 悲伤
5. 恐惧
6. 惊讶
7. 厌恶
8. 坚定

每种表情说明眉眼、嘴角、视线、头部姿态和习惯动作的组合。不要让所有人物都用“皱眉、抿唇、眼神冰冷”表达不同情绪。

### 人物兑现计划

在角色设定中记录：

- 首次出场用哪个行动建立人物。
- 主角在开篇前三章、其他核心人物在首次登场后的三章内分别用什么事件证明主要特征。
- 哪个特征会制造收益，哪个特征会制造错误或代价。
- 人物在中点和高潮前后哪些行为会改变，哪些底层特征保持稳定。

读者应当能够在隐去姓名后，通过语言、动作和选择判断是谁，而不只依赖外貌标签。

## 场景设定

`06_场景设定.md` 记录会影响人物行动、冲突、氛围或连续性的地点。

每个重要场景记录：

- 场景 ID、固定名称、地点类型和首次出现章节。
- 所属势力、主要使用者、准入条件和社会规则。
- 固定空间骨架：入口、出口、楼层、高低差、遮挡和关键位置的相对关系。
- 光线、色彩、声音、气味、温度和主要材质。
- 三至五个稳定视觉锚点。
- 人物可以利用的设施、危险、资源、藏身处和逃生路径。
- 场景对人物施加的现实压力和情绪压力。
- 初始状态、发生变化的章节和当前状态。
- 漫剧中可复用的固定部分与必须随剧情变化的部分。

重复场景沿用同一名称和空间骨架。火灾、洪水、战斗破坏、装修、季节或所有权变化需要记录生效章节，后续正文不能无解释恢复旧状态。

环境描写优先服务以下至少一项：

- 限制或帮助人物行动。
- 暴露人物观察方式。
- 改变关系距离或权力位置。
- 提供证据、危险或选择。
- 形成可重复识别的视觉记忆。

## 道具、装备与武器设定

`07_道具装备设定.md` 管理线索、信物、工具、消耗品、装备和武器。

### 核心道具与长期装备

记录：

- 道具 ID、名称、类别、来源和制造者。
- 初始持有人、当前持有人和当前位置。
- 外观、颜色、尺寸感、材质、纹样、标记和辨识性损伤。
- 剧情作用、象征意义和固定视觉锚点。
- 使用方法、能力边界、代价和限制。
- 耐久、数量、消耗次数、损坏和修复状态。
- 首次出现、关键使用、转交、遗失、损坏和回收章节。
- 后续兑现计划及不能随意改变的属性。

多次出现的普通物件只需记录外观、用途、持有人和状态。没有连续性影响的一次性物件无需建卡。

### 主要武器

只有题材和剧情实际需要时才建立武器条目。除核心道具字段外，再记录：

- 武器类型、长度、重量感和有效距离。
- 携带、收纳和拔取方式。
- 使用者所需能力与熟练程度。
- 主要攻击、防御和限制方式。
- 杀伤后果、耐久、弹药或能量消耗。
- 使用它产生的法律、身份或社会风险。

只保留会影响战斗结果、人物选择或视觉一致性的参数，不制作无剧情作用的游戏数值表。非战斗作品不要为了模板完整凭空增加武器。

## 章节规划闭环

每章规划在追读字段之外记录：

- 视角人物和出场人物。
- 本章需要展示的人物特征。
- 特征通过哪个动作、语言、选择或关系反应成为证据。
- 主场景 ID、场景压力和可互动元素。
- 使用、转交、遗失或损坏的道具、装备和武器。
- 章节开始时的持有人、位置和状态。
- 本章造成的场景、造型和物件变化。
- 章节结束后的新状态。

写作前读取本章相关角色、场景和物件条目，形成内部连续性清单。不要把清单和字段名写入正文。

每个重点人物只选择与当前冲突最相关的一至两个特征进行表现。主角的主要特征需要在开篇前三章形成可观察证据；其他核心人物在首次登场后的三章内完成同类证明。不要求每章重复全部特征。

正文定稿后同步更新：

- `04_创作进度.md` 的人物、场景和物件当前状态。
- `05_追读账本.md` 的相关期待与兑现。
- `06_场景设定.md` 的永久变化。
- `07_道具装备设定.md` 的持有、消耗、损坏和回收。
- `漫剧改编/00_视觉资产总表.md` 中有剧情依据的视觉变化。

## 漫剧视觉资产

`漫剧改编/00_视觉资产总表.md` 固定：

- 人物的年龄感、身材比例、面部、发型、服装材质、配饰、标志性元素、表情库、姿态和气质。
- 场景的固定名称、空间骨架、色彩、光线、材质、标志物和当前版本。
- 关键物件的外观、材质、尺寸感、标记、当前状态和连续性要求。

单集改编资料继承总表，只记录本集有剧情依据的换装、伤势、天气、破坏或物件状态变化。

`style_tags`、`negative_prompt` 和 `seed_hint` 属于可选图像生产参数，放在视觉资产总表。没有实际图像生成需求时省略，不保留空白字段。

## 章节编号

新作品统一使用四位数章节编号：

```text
正文/第0001章_章节标题.md
正文/第0002章_章节标题.md
```

正文一级标题使用相同编号：

```markdown
# 第0001章 章节标题
```

章节规划、创作进度、追读账本和漫剧资料引用正文时使用四位数编号。

续写旧作品时先识别原有编号宽度并保持原格式。除非用户明确要求迁移，不批量重命名旧文件或修改既有引用。

## 冲突处理

- 设定与已经明确写入正文的事实冲突时，优先保留正文事实，再修正设定。
- 多份设定互相冲突且无法从正文判断时，停止扩大矛盾，指出冲突并给出最小改动方案。
- 旧作品缺少场景或道具档案时，从正文提取已确认事实并补建最小可用记录。
- 不为补齐档案凭空发明伤疤、武器、配饰或场景结构。
- 尚未被正文建立的信息明确写为“正文尚未建立”，不使用空白字段。

## 完成检查

- [ ] 核心人物同时具备叙事人格、可观察特征和固定视觉身份
- [ ] 主角在开篇前三章、其他核心人物在登场后三章内形成主要特征证据
- [ ] 不同核心人物的语言、动作和选择逻辑可以区分
- [ ] 重要场景具有稳定空间骨架、视觉锚点和当前状态
- [ ] 核心道具与主要武器具有来源、边界、持有人和状态变化
- [ ] 非战斗作品没有为了填表凭空增加武器
- [ ] 漫剧单集资料继承视觉资产总表
- [ ] 新作品从 `第0001章` 开始，文件名与正文标题编号一致
- [ ] 旧作品保持原编号和既有事实
