# 通用角色三视图提示词

把单个人类或类人角色整理成标准角色设定板提示词。画面固定为上半身特写加正、侧、背三个全身视图，结构对照与角色一致性优先于装饰效果。

## 适用边界

- 每次只处理一名具有稳定直立躯干结构的人类或类人角色，包括精灵、兽人、机器人、改造人和拟人动物。
- 不处理四足、蛇形、无定形生物、多角色同板、武器展示板或黑金多栏目设定集。
- 用户明确要求古风美女、古风男主或固定超写实 3D 国漫风格时，优先使用对应专项 Skill；用户要求通用画风、参考图复刻或非古风类人角色时使用本 Skill。
- 只生成提示词，不调用图像生成工具。

## 工作流程

### 1. 判断输入是否足够

接受文字描述、角色卡、小说人物设定和参考图片。

只有角色身份、性别或物种、核心视觉方向等决定性信息缺失时，才提出一个关键问题。普通细节缺失时直接保守补全，不逐项询问。

遇到以下情况时先停止生成：

- 参考图片无法读取或人物被严重遮挡：请用户重新提供清晰图片。
- 输入包含多名角色：请用户指定本次处理的一名角色。
- 角色不具备可采用标准直立姿态的躯干结构：简短说明本 Skill 不适用。

### 2. 合并角色资料

按以下优先级处理冲突：

1. 用户本次明确提出的保留或修改要求。
2. 参考图片中可见的角色特征。
3. 角色卡、小说人物设定或其他文字资料。
4. 根据已有设计语言作出的保守推断。

用户要求修改的特征覆盖参考图；未要求修改的可见特征继续由参考图锁定。

### 3. 锁定角色身份

读取 [identity-lock.md](references/identity-lock.md)，在内部建立一致性清单。不要把清单展示给用户。

不可见背部延续正面材质、配色和结构逻辑，采用对称、低复杂度设计。不要凭空增加复杂纹样、开口、大型装饰或新的配饰。

### 4. 确定视觉风格

按以下顺序确定画风：

1. 严格继承用户明确指定的视觉风格。
2. 用户未指定时，保持参考图片的媒介和画风。
3. 两者都没有时，使用高端半写实 3D 角色概念设计。

高精度不等于强制写实。不得把二次元、卡通或风格化角色擅自真人化。

### 5. 组装提示词

读取 [prompt-template.md](references/prompt-template.md)，把已锁定的角色信息写成一段自然、完整、平台无关的中文提示词。

提示词必须完整描述角色，而不是只写“与参考图一致”。对参考图可见的脸、头发、体型、服装和配饰使用明确文字锚定，降低不同视图自行改造角色的概率。

### 6. 交付前检查

确认提示词同时满足：

- 16:9 横版、8K、纯白无缝纯净背景、影视级三点布光。
- 从左到右严格为上半身特写、全身正视图、全身侧视图、全身背视图。
- 特写约占 28%，三个全身视图各约占 24%。
- 三张全身图使用同尺度自然 A-Pose，并明确 0°、90°、180°朝向。
- 脸、体型、发型、服装、纹样和固定配饰跨视图锁定。
- 禁止武器、手持物、独立道具、Logo、水印、标尺、额外角色、裁切和重叠；不要加入禁止文字、标题或视图标签的约束。
- 不含特定图像平台的命令或参数。

“100% 一致”是提示词中的强约束目标，不要声称可以保证图像模型的最终生成结果达到数学意义上的完全一致。

## 输出格式

信息充分且任务在适用范围内时，最终响应只包含一个 `text` 代码块。代码块中放一段完整、连续、可直接复制的中文提示词。

不要输出标题、解释、角色分析、锁定清单、变量表、备选版本或独立 Negative Prompt。
