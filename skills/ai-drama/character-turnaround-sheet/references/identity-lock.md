# 角色身份与跨视图一致性锁定

生成提示词前，先在内部完成本页检查。目的不是堆砌形容词，而是找出能让四栏明确属于同一角色的稳定视觉锚点。

## 1. 锁定层级

### 身份与比例

- 角色身份、性别或物种、年龄段。
- 身高感、头身比、肩宽、躯干长度、四肢比例和体型轮廓。
- 类人非人角色的耳朵、角、尾巴、机械关节或其他稳定结构。

### 面部

- 脸型、颧骨与下颌轮廓。
- 眉形、眼型、眼距、瞳色、鼻型、唇形和肤色。
- 雀斑、痣、疤痕、面纹等识别标记的精确侧别与位置。
- 上半身特写与全身正视图必须保持相同五官比例和年龄感。

### 发型

- 发色、发量、发际线、刘海分区和头顶轮廓。
- 束发点、编发路径、发髻数量、发尾长度和后脑结构。
- 侧视与背视只能揭示已有结构，不得发明另一套发型。

### 服装

- 内外层顺序、领型、袖型、衣长、腰线和下装轮廓。
- 主色、辅色、点缀色及其分布区域。
- 面料、金属、皮革、毛发或机械材料的质感。
- 纹样、接缝、扣件、开口和不对称剪裁的具体侧别。
- 正、侧、背三个视图使用同一套服装，不换装、不增减层级。

### 固定配饰

- 记录耳饰、徽章、腰带、护甲组件等固定配饰的名称、数量、尺寸、方向和佩戴位置。
- 不对称配饰必须明确位于角色自身的左侧或右侧，不能随镜头镜像翻转。
- 禁止武器、手持物和独立陈列道具。

## 2. 参考图片处理

先描述能实际看见的特征，再处理遮挡区域。不要用“完全参考原图”代替明确特征描述。

当用户要求修改参考图时：

1. 只替换用户明确指定的特征。
2. 保留其他可见的身份锚点、身体比例、媒介与画风。
3. 让新增设计沿用原有形状语言、材质和复杂度。

参考图看不到背部时，延续正面已有的领口、肩部、腰线、下摆、材质和配色逻辑。默认采用对称、封闭、低复杂度结构，不新增大型图案、镂空、披挂或装饰件。

## 3. 类人非人角色

- 精灵耳、兽耳、角、尾巴和机械部件必须在适用视图中保持数量、形状、尺寸、颜色和连接位置一致。
- 对机器人或改造人，锁定面板分区、关节结构、发光部位和左右不对称模块。
- 对拟人动物，保持物种特征和直立比例，不擅自改成人类皮肤或普通人耳。
- 任何附加结构都不得遮挡全身轮廓或破坏标准 A-Pose。

## 4. 内部复核

在写入最终提示词前确认：

- 每个稳定识别点都有明确文字描述。
- 不对称信息使用角色自身左右方向，而不是画面左右方向。
- 侧视和背视只揭示结构，不增加新设计。
- 四栏的年龄、体型、脸、发型、服装版本和配饰完全相同。
