# 通用角色三视图提示词模板

按下列顺序组织最终提示词。写成一段连续、自然的中文描述，不保留字段名、占位符或分节标题。

## 1. 画面规格

开头明确这是 16:9 横版、8K 超高清、高精度角色设定板，并写出用户指定或按规则确定的视觉风格。

背景固定为纯白、无缝、均匀、无纹理的纯净背景。画面不出现地平线、环境、装饰框或场景物体。

## 2. 四栏版式

明确从左到右的严格顺序：

1. 正面上半身特写。
2. 0°全身正视图。
3. 90°全身侧视图。
4. 180°全身背视图。

上半身特写约占画面宽度 28%，三个全身视图各约占 24%。四栏保留均匀留白，互不重叠。

特写展示头部、肩部、胸部上方和关键上装细节。三个全身视图必须从头顶到鞋底完整入画，使用相同镜头高度、焦距、人物尺度和正交观察感；头顶线、肩线、胯线和脚底线对应一致。

## 3. 角色描述

依次写清：

- 身份、性别或物种、年龄段、身高感、头身比和体型。
- 脸型、眉眼、瞳色、鼻唇、肤色和稳定识别标记。
- 发色、发际线、刘海、主体发型、束发结构和背部发型。
- 服装由内到外的层级、剪裁、颜色、材质、纹样和闭合方式。
- 固定配饰的数量、尺寸、方向和佩戴位置。
- 类人非人结构的形状、数量、颜色与身体连接位置。

只写已提供或按一致性规则补全的细节，不加入武器、手持物或独立道具。

## 4. 姿态与一致性

三个全身视图统一采用自然 A-Pose：角色直立，双臂自然下垂并与躯干略微分开，双脚平行稳定站立，表情中性。

明确写出“四个视角人物特征 100% 一致”，并说明四栏是同一角色、同一年龄、同一体型、同一张脸、同一发型和同一套服装。锁定材质、纹样、接缝、扣件、配色及固定配饰；不镜像不对称设计，不在侧面或背面新增结构。

## 5. 光影与质量

使用中性影视级三点布光：柔和主光、低强度补光、克制轮廓光。四栏保持相同色温、曝光、阴影方向和材质表现。

强调清晰轮廓、高精度纹理、完整边缘和与目标画风一致的材质表现。避免戏剧性逆光、彩色环境光、硬阴影、过度景深和透视畸变。

## 6. 末尾约束

在同一段提示词末尾自然整合以下限制：

- 不出现 Logo、水印或标尺。不要添加禁止文字、标题或视图标签的约束。
- 不出现武器、手持物、独立道具、额外角色或额外肢体。
- 人物不重叠、不裁切、不越界，不改变服装或配饰。
- 不出现环境背景、动态动作、夸张透视或不同视图的光影变化。

不要加入 Midjourney、即梦或其他平台专用命令、参数和独立 Negative Prompt。
