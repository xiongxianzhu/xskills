# 逐镜视频提示词（即梦 / Seedance 2.0 主路径）

主路径按即梦 / Seedance 2.0 的实际限制写，其他模型作为可替换次路径。提示词的目标是「一次生成可用」，不是把剧本塞进去。

## 1. 平台限制与参数

| 项目 | 即梦 / Seedance 2.0 | 处理方式 |
| --- | --- | --- |
| 单段时长 | 4–15 秒整数 | 长动作拆成两段，用首帧接力 |
| 提示词长度 | ≤ 2000 字 | 常规镜头 150–300 字，关键镜头不超过 600 字 |
| 画幅 | 16:9 横屏或 9:16 竖屏，未指定时默认 16:9 | 面板与提示词填写同一选定比例 |
| 参考图 | 支持多图，用 @ 引用 | 每镜最多 3 张，写明用途 |
| 首尾帧 | 支持首帧 / 尾帧 | 只用于关键动作与精确构图 |
| 字幕 | 生成画面常自带乱码文字 | 提示词开头写「画面无任何字幕」，字幕后期加 |

面板参数与提示词必须双写：未指定画幅时，面板选 10 秒 / 16:9，提示词的【风格】行也写「10 秒，16:9」；项目指定 9:16 时，两处都改为 9:16。每条提示词只写一个选定比例，不把「16:9 或 9:16」原样交给模型。

## 2. 提示词骨架

```text
画面无任何字幕。

【风格】{风格}，{N}秒，{选定画幅，未指定时填16:9}，{一句话氛围}
【主体】{身份锁定句}，{当前形态与服装}
【构图】{按选定画幅写主体位置、视线留白与字幕预留区}
【动作】{一个主动作 + 不超过 2 个连续小动作}
【环境】{前中后景各一个元素}，{天气或空气状态}
【光影】{主光方向}，{色温}，{对比度}，{一个材质高光}
【运镜】{一种运镜}
【声音】（{配乐情绪}）+<{音效}>+{角色台词}
【约束】{正向约束，2–3 条}
【参考】@图片1 {用途}
```

完整示例（10 秒，默认 16:9 横屏）：

```text
画面无任何字幕。

【风格】3D 国漫 CG，10 秒，16:9，冷灰森林，压迫感
【主体】灰白短毛拟人兔，3.5 头身，左耳缺三分之一，右眼灰白，左眼琥珀，右前爪缠麻绳，腰缠破布，背一只藤篓
【构图】主角位于左侧三分线，右侧留出雾中森林与视线空间，下方预留字幕区
【动作】他趴在巨大狼尸背上，缓缓抬头，舔掉爪尖的血，左耳抽动两下
【环境】前景焦黑断木，中景狼尸与散落骨片，后景雾中树影，空气里有未散的血雾
【光影】左上方冷月光为主光，右侧微弱暖火光补光，低饱和，毛发表面有湿润高光
【运镜】镜头从爪部缓慢上摇到面部，最后停住
【声音】（低频弦乐渐入）+<布料摩擦、远处狼嚎>+{不配留下？那我吃给你们看。}
【约束】兔与狼体型比例保持三倍以上差距，动作低缓连续，毛发与藤篓细节稳定
【参考】@图片1 主角外观与配色
```

切换为 9:16 时，同步修改面板和【风格】，把【构图】改为「主体居中略偏上，森林沿纵深展开，下方预留字幕区」，并重新准备同画幅的场景首尾帧。角色设定参考图可保留原图，不能通过拉伸角色或直接裁掉关键动作来凑画幅。

## 3. 五条硬规则

1. **一镜一动作**：只写一个主动作，最多补两个连续小动作（抬头、舔爪、耳朵抽动属于同一动作链）。
2. **单镜单运镜**：一种运镜写到底，不写「推近后环绕再拉远」。
3. **时长比例双写**：面板 + 【风格】行各写一次。
4. **正向约束**：不用「不要、禁止、严禁」，改写成期望状态。
5. **台词用 `{}`**：音乐用 `（）`，音效用 `<>`，便于后期拆分与配音。

## 4. 文生视频与图生视频

| 场景 | 选择 | 原因 |
| --- | --- | --- |
| 首次出现的场景 | 文生视频 | 没有可参考构图 |
| 含固定角色 | 图生视频 + 角色参考图 | 保证一致性 |
| 关键情绪特写 | 图生视频 + 首帧图 | 表情可控 |
| 连续动作接续 | 图生视频 + 上一镜末帧 | 动作连贯 |
| 形态进化瞬间 | 首尾帧 | 起止状态明确 |

首尾帧法的提示词只写中间过程，控制在 80 字内：

```text
画面无任何字幕。灰白拟人兔的胸口甲壳从裂纹中撑开，金色纹路沿血管蔓延到颈侧，身体微微弓起，毛发被气流掀起，左耳保持缺口。冷月光，正面微仰，固定机位，5 秒，16:9。
```

## 5. 口型与台词

中文视频模型的口型精度有限，按成本排序：

1. 侧脸、背身、低头、遮挡口部说话，后期配音对位。
2. 台词镜用近景但不对口型，靠字幕承担信息。
3. 必须正脸说话时，单句 ≤ 8 字，慢语速，生成后不追口型。
4. 旁白镜头不需要口型，优先用环境镜头或背影。

不要在提示词里写「精确对口型」「口型与台词一致」，模型无法执行，只会增加画面抖动。

## 6. 模型替换

换模型时改字段映射，不改内容结构：

| 字段 | 即梦 / Seedance 2.0 | 可灵 / 海螺 / Vidu / Runway 等 |
| --- | --- | --- |
| 时长 | 面板 4–15 秒 + 文本双写 | 面板选 5 / 10 秒或首尾帧时长 |
| 画幅 | 按项目选择 16:9 或 9:16，未指定时默认 16:9 | 使用同一画幅；模型不支持时先说明限制，选择支持的模型或经确认后重构画面 |
| 参考图 | @图片 N | 首帧图 / 角色参考 / 图片提示 |
| 运镜 | 【运镜】文字描述 | 有运镜面板时面板优先，文本只写方向 |
| 负面提示 | 正向约束为主 | 有独立 negative 框时再补，不重复写 |
| 首尾帧 | 支持 | 部分模型仅支持首帧 |

替换后先跑 2 个镜头验证一致性与时长，再批量。

## 7. 约束写法：负向改正向

| 负向写法（不用） | 正向写法（用） |
| --- | --- |
| 不要出现字幕 | 画面干净，无任何文字元素 |
| 不要多手多脚 | 四肢数量正常，动作低缓连续 |
| 不要血腥 | 用光影与反应表现冲击，画面保持克制 |
| 不要变形 | 头身比与服装细节全程稳定 |
| 不要慢动作 | 动作节奏接近真实速度 |
| 不要模糊 | 主体清晰，浅景深只作用于背景 |

## 8. 错误与正确

错误（文学描写，无法执行）：

> 夕阳下，他孤独地站在废墟中央，内心充满悲凉。

正确（可拍的镜头语言）：

> 低机位仰拍，角色背对镜头站在断墙前，肩膀微塌，尾巴垂地，夕阳从左后方掠过形成长影，镜头缓慢后拉。

错误（复合动作）：

> 他冲上去咬住狼王喉咙，把它甩飞出去，然后仰天长啸。

正确（拆成三镜）：

> 镜 A：后腿蹬地腾空，嘴张开。镜 B：牙齿接触咽喉，血珠溅到镜头。镜 C：狼王倒地扬尘，兔子落地喘气。

## 9. 单镜检查

- [ ] 面板、提示词和场景首尾帧使用同一选定画幅；时长已双写，未指定画幅时默认 16:9。
- [ ] 开头有「画面无任何字幕」。
- [ ] 身份锁定句原样复用，锚点齐全。
- [ ] 只有一个主动作、一种运镜。
- [ ] 光影写了方向、色温和一个材质高光。
- [ ] 约束是正向表述，2–3 条。
- [ ] 参考图写明用途，总数 ≤ 3。
- [ ] 台词单句 ≤ 18 字，标点不进入配音。

## 10. 批量输出格式

每镜一个块，便于逐条复制：

````markdown
### 镜 07
- 时长：8 秒　画幅：16:9（未指定时的默认值）　生成方式：图生视频 + 首帧接力
- 参考图：@图片1 主角外观；@图片2 上一镜末帧
- 景别 / 运镜：近景 / 推

```text
画面无任何字幕。
【风格】……
```

- 台词：兔子：不配留下？那我吃给你们看。
- 音效：吸气、金属震颤
- 备注：若脸部漂移，改用局部重绘
````

## 11. 常见生成故障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 多手多脚 | 动作复杂、角色重叠 | 拆镜，减少同时在画人数 |
| 脸部逐帧变形 | 参考图不足或描述每镜不同 | 固定锁定句 + 同一张定妆图 |
| 动作像慢动作 | 描述了慢镜头或高难度动作 | 删「缓慢」「慢动作」，改低幅度动作 |
| 画面出现乱码文字 | 场景含招牌、书页、面板 | 开头禁字幕，文字类内容后期叠加 |
| 镜头自己乱动 | 运镜描述冲突 | 只留一种运镜，必要时写「固定机位」 |
| 场景每镜都变 | 环境描述太笼统 | 补前中后景各一个固定元素 |
| 时长不够用 | 单段超 15 秒 | 拆两段，用末帧接力 |
