# 角色资产与跨镜一致性

AI 视频最贵的成本不是生成，是返工。角色一致性靠资产前置，不靠每镜重新描述。

## 1. 角色资产卡

每个角色一张卡，字段一次写全，后续所有镜头从这里取词。

| 字段 | 内容要求 | 示例 |
| --- | --- | --- |
| 名称 | 片中称呼，固定不变 | 断耳 |
| 物种与形态 | 动物种类、拟人程度 | 兔，拟人，双足站立 |
| 年龄感 | 幼年 / 少年 / 成年 / 老年 | 少年 |
| 头身比 | 明确比例，避免各镜漂移 | 3.5 头身 |
| 体型 | 身高、肩宽、胖瘦 | 矮壮，肩窄臀宽 |
| 主色 | 一个主色 + 一个辅色，给色值 | 主色灰白 #E8E4DC，辅色土黄 #B08A5A |
| 毛发 / 甲壳 | 质感与纹理方向 | 短毛，胸口有一撮逆毛 |
| 眼睛 | 颜色、形状、异色与否 | 左眼琥珀，右眼灰白（盲） |
| 标志特征 | 一眼能认出的缺陷或印记 | 左耳缺三分之一，断口结痂 |
| 配饰 | 位置写清左右 | 右前爪缠麻绳，左耳挂骨环 |
| 服装 | 默认装 + 备用 2 套 | 无上衣，腰缠破布，背一只藤篓 |
| 武器 / 道具 | 材质、尺寸、持握方式 | 一截狼牙，长约前臂，反握 |
| 进化阶段 | 当前阶段与触发条件 | 一阶「噬忆」，吞三份记忆后进二阶 |
| 动作习惯 | 每次都要出现的小动作 | 思考时左耳抽动 |
| 声线 | 音色、语速、口音 | 少年音，偏哑，语速快 |

进化或重生题材额外加：

| 阶段 | 触发条件 | 新增识别特征 | 保留锚点 | 主色变化 |
| --- | --- | --- | --- | --- |
| 一阶 | 初始 | 断耳、灰白毛 | 断耳 | 灰白 |
| 二阶 | 吞三份记忆 | 胸口金色纹路 | 断耳、右眼盲 | 灰白 + 金纹 |
| 三阶 | 吞狼王心核 | 背后骨刺 | 断耳、金纹 | 灰白 + 金 + 黑 |

规则：每次进化只新增一个识别特征，至少保留一个原始锚点（如断耳）。观众靠锚点认人。

## 2. 生成顺序

```text
资产卡 → 角色设定板 → 定妆图（默认装） → 表情包 → 形态图 → 道具图
```

设定板必须包含：

1. 正面全身（A-Pose，双臂微张，不遮挡身体轮廓）
2. 3/4 侧全身
3. 背面全身
4. 面部特写（正脸，眼睛看镜头）
5. 四个表情：平静、愤怒、惊恐、得意
6. 纯色背景，无场景、无文字、无多余角色

定妆图用于视频参考，要求与设定板同色温、同光源方向。图存 `04_角色/参考图/`，命名 `角色名_视图_版本.png`，如 `断耳_正面_v1.png`。

## 3. 身份锁定句

从资产卡提炼一段 ≤ 40 字的固定描述，此后每个镜头原样复用，不改写、不缩写：

```text
灰白短毛拟人兔，3.5 头身，左耳缺三分之一，右眼灰白，左眼琥珀，右前爪缠麻绳。
```

使用规则：

- 放在每条提示词的主体描述最前面。
- 不因为景别改变而删减锚点；特写也要带断耳或盲眼。
- 新增形态时另写一条锁定句，旧句保留给回忆镜头。

## 4. 参考图复用策略

| 策略 | 用法 | 适用 |
| --- | --- | --- |
| 角色参考图 | 每镜附加同一张定妆图，提示词写明「角色外观参考图 1」 | 所有含角色的镜头 |
| 首帧图 | 先用生图模型出该镜首帧，再用首帧生成视频 | 关键动作、情绪爆发 |
| 首帧接力 | 用上一镜最后一帧作为下一镜首帧 | 连续动作、同一场景对话 |
| 局部重绘 | 只重绘脸或配饰区域 | 轻微漂移，不想重生成整镜 |
| 多角色参考 | 每个角色一张图，提示词逐一绑定 | 双人对峙、群戏 |

参考图数量控制在 3 张以内。图越多，模型越容易混淆主次。

## 5. 一致性检查

任意两镜并排，逐项核对：

- [ ] 头身比一致，没有一会儿 2 头身一会儿 5 头身。
- [ ] 主色一致，没有灰白变纯白或变棕。
- [ ] 缺陷位置一致：断耳在左，盲眼在右。
- [ ] 配饰左右一致：麻绳在右前爪，骨环在左耳。
- [ ] 服装磨损与污渍程度一致。
- [ ] 眼睛颜色与光感一致。
- [ ] 光源方向一致：同一场景内主光不换边。
- [ ] 道具尺寸一致：狼牙长度不超过前臂。

同一场景内还要检查背景：树木朝向、岩石位置、地面材质不能每镜都变。

## 6. 漂移修复

按成本从低到高选择：

| 现象 | 首选修复 | 仍不行 |
| --- | --- | --- |
| 脸型轻微变化 | 局部重绘脸部 | 用首帧图重生成该镜 |
| 配饰跑到另一侧 | 提示词补「麻绳在右前爪」并加参考图 | 重出定妆图，统一左右 |
| 主色偏移 | 提示词加色值 | 重生成并锁定同色温 |
| 形态比例失控 | 补「3.5 头身」并降低动作幅度 | 拆镜，改为中景或特写 |
| 多角色混淆 | 减到两个角色，逐一绑定参考图 | 拆成单人镜头正反打 |
| 进化形态认不出 | 强化保留锚点（断耳） | 重做形态设计，只改一个特征 |

连续三镜都修不好，说明资产卡写得不具体，回第 4 步重写，不要继续硬修。

## 7. 拟人动物专项

- 头部保留动物特征（耳朵、口鼻、眼睛位置），身体用人类体态，关节按人类活动。
- 手部统一：四指或五指全片一致，不做特写就不强调手指数量。
- 尾巴是否可见要写进资产卡；可见时注意穿模，动作幅度收小。
- 表情靠耳朵、眉区、瞳孔和口鼻开合，不只靠嘴角。
- 服装要适配体型：藤篓、腰带、披风比成套衣服更稳，减少布料模拟崩坏。
- 动物品种一旦确定不换：兔不能一会儿像鼠一会儿像猫。

## 8. 重生与进化题材专项

- 前世与今生用两套锁定句，靠服装、伤疤或发型区分，避免观众混淆。
- 每次进化给一个可见仪式：光效、裂纹、蜕壳，时长 1–2 秒，固定在爽点位置。
- 形态越多，单集只展示一种主形态，其余用回忆或远景带过。
- 数值面板用后期 UI 叠加，不让模型生成文字，避免乱码。
- 反派也要建资产卡，至少写主色、体型、标志武器三项。
