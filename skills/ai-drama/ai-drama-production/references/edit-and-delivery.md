# 剪辑、成片与发布

剪辑决定观众能不能看完，发布物料决定能不能被点开。两者都按清单执行，不靠手感。

## 1. 剪辑顺序

固定六步，不跳步：

1. **粗剪**：先按立项设置 16:9 或 9:16 画布，未指定时默认 16:9；按分镜表顺序拼接，保证时长与叙事完整。
2. **节奏修剪**：删掉每镜开头和结尾的静止帧（0.2–0.4 秒），去掉重复动作。
3. **声音**：铺配音 → 音效 → BGM，按情绪曲线卡点。
4. **字幕**：逐句对齐，关键词强调。
5. **调色**：统一色温、对比度与饱和度，同一场景不跳色。
6. **封面与导出**：截封面帧，按规格导出。

## 2. 节奏规则

- 前 3 秒不放开场空镜、Logo、片头。
- 每 2–3 秒必须有画面变化（剪辑、运镜、光线、表情）。
- 单镜超过 4 秒时，中间必须有动作或光线变化，避免 PPT 感。
- 爽点前留 0.2–0.4 秒静默或减速，爽点后给 0.5 秒反应镜头。
- 集尾定格 0.3–0.5 秒再结束，不用淡出到黑。
- 相邻两集不重复同一段 BGM 和同一组空镜。

## 3. 字幕规范

| 项目 | 规范 |
| --- | --- |
| 位置 | 16:9 建议位于画面高度 80–90%，底部留约 10%；9:16 建议位于 75–85%，底部留约 15%；按实际平台 UI 调整 |
| 字号 | 按目标播放尺寸检查可读性；9:16 单行建议 ≤ 12 字，16:9 可用 12–18 字，不能为塞字而缩小字号 |
| 行数 | 最多两行，不遮主体面部 |
| 颜色 | 白字 + 深色描边或半透明底，不用纯色块铺满 |
| 强调 | 关键词放大 1.2 倍或换色，每集 ≤ 8 处 |
| 标点 | 句中不出现逗号句号，用换行和停顿替代 |
| 错别字 | 导出前逐句校对，重点查同音字与角色名 |

## 4. 调色

- 同一场景统一色温，冷场不出现暖光镜头。
- 前世、回忆用低饱和 + 冷色，今生用正常饱和。
- 进化、觉醒段落允许局部提高饱和度与高光，但不超过 2 秒。
- 全片对比度一致，避免一段灰一段艳。

## 5. 导出参数

| 参数 | 值 |
| --- | --- |
| 分辨率 | 16:9 为 1920×1080；9:16 为 1080×1920 |
| 比例 | 按立项选择 16:9 或 9:16，未指定时默认 16:9 |
| 帧率 | 30fps |
| 编码 | H.264 |
| 码率 | 8–12 Mbps |
| 音频 | AAC 192 kbps，48 kHz |
| 容器 | MP4 |
| 单集时长 | 45–120 秒，默认 75 秒 |

导出画幅必须与分镜、生成素材和剪辑画布一致。需要另一画幅版本时，重新检查构图与字幕布局，不拉伸角色，不直接裁掉关键动作。

导出后必须在目标播放尺寸与全屏下各回看一遍，检查字幕遮挡、音画同步、结尾是否被截断。

## 6. 封面与标题

封面：

- 从成片截 3 帧候选：冲突帧、奇观帧、角色正脸帧。
- 封面按目标平台展示比例排版；与成片画幅不同时单独适配，不能因此改变成片画幅。
- 大字 4–8 字，写结果或冲突，如「我吞了狼王」。
- 主体占 1/3 以上，眼睛不被文字遮挡。
- 与标题讲同一个卖点，不各说各的。

标题：

- 12–22 字，前 12 字给身份或结果。
- 一条只讲一件事。
- 不带夸张标题党词。

发布信息：

| 项目 | 要求 |
| --- | --- |
| 话题 | 3–5 个，2 个赛道词 + 1–2 个题材词 + 1 个泛流量词 |
| 合集 | 建同名合集，按集顺序放入 |
| 置顶评论 | 一句追更钩或互动问题，引导评论 |
| 发布时间 | 固定时段，按账号数据调整，不频繁变动 |
| AI 标识 | 按平台当期要求标注 AI 生成内容 |

## 7. 发布前检查

- [ ] 成片使用立项选定的 16:9 或 9:16，未指定时默认 16:9；无意外黑边、无拉伸或关键内容被裁切。
- [ ] 前 3 秒有钩子，无片头 Logo。
- [ ] 字幕无错别字、不挡脸、不超出安全区。
- [ ] 音画同步，台词与口型或动作对得上。
- [ ] 人声清晰，BGM 不盖台词，手机外放通过。
- [ ] 结尾钩完整，没有被平台截断。
- [ ] 标题、封面、前 3 秒讲同一个卖点。
- [ ] 合集已建，前一集已放入。
- [ ] 合规复核：无血腥特写、无虐待动物画面、无迷信引导、无未成年人危险模仿。
- [ ] AI 生成标识按平台当期规则处理。
- [ ] 音乐、音效、字体授权可查。
- [ ] 导出文件命名规范：`剧名_EP01_日期.mp4`。

## 8. 数据复盘

发布 24 小时与 72 小时各记录一次：

| 指标 | 看什么 | 归因方向 |
| --- | --- | --- |
| 3 秒留存 | 开头钩子是否有效 | 低于账号均值：换开场或第一句台词 |
| 完播率 | 中段是否拖 | 低：删解释、压镜长、提前爽点 |
| 平均播放时长 | 流失点位置 | 对照分镜表找具体镜头 |
| 追更评论 | 观众是否记住角色 | 弱：加强角色锚点与关系 |
| 点赞 / 评论比 | 情绪是否被触发 | 低：补反应镜头与台词 |

迭代规则：一次只改一个变量，改完至少跑 3 集再判断。不因单集数据波动推翻整季结构。
