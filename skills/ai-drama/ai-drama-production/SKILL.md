# AI 漫剧全流程制片

把「选题 → 集纲 → 剧本 → 角色资产 → 分镜 → 逐镜提示词 → 配音配乐 → 剪辑成片 → 发布复盘」串成一条可执行的生产线。每步都给出模板、换算和验收门槛，产出物可直接交给下一环节或生成工具。

## 适用与边界

适用：

- 拟人动物冒险、重生修炼、吞噬进化、系统流、复仇逆袭等连续剧情短剧。
- 单集 45–120 秒、16:9 横屏或 9:16 竖屏、20–60 集，日更或隔日更。
- 从零立项，或已有小说 / 创意需要落地成可发布成片。

不适用时改用对应技能（本技能不重复其单点工作）：

- 写小说正文、续写、修文：ai-novel-writer。
- 只把小说润色成短视频文案：manju-short-video-polish。
- 只把小说拆成分镜脚本：novel-to-script。
- 只做一条工业级分镜：industrial-storyboard。
- 只做单段 Seedance / 即梦提示词：seedance-storyboard、jimeng-split-prompts。
- 只做角色三视图或设定板提示词：character-turnaround-sheet、character-design-board。

本技能不调用生图、生视频、配音 API，只产出可执行的文档、提示词、表格和检查结果。用户要求直接生成素材时，说明需要外部工具，交付提示词与参数。

## 默认参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 平台 | 抖音 | 完播与 3 秒留存优先，不因平台自动限定画幅 |
| 画幅 | 16:9 横屏，1920×1080 | 支持 9:16 竖屏，1080×1920；同一成片全流程统一 |
| 单集时长 | 75 秒 | 首集 60–75 秒；卡点集可压到 45 秒 |
| 集数 | 30 集 | 先做 3 集验证，再批量 |
| 单集镜头数 | 24–32 | 平均 2.4–3.0 秒/镜 |
| 单集场景数 | 3–5 | 超过 5 个场景先合并 |
| 旁白语速 | 4.5 字/秒 | 角色台词 3.8–4.5 字/秒 |
| 视觉风格 | 3D 国漫 CG | 风格词全流程一致 |
| 配音 | 试音后定 TTS 或真人 | 单集先出 15 秒样音 |
| 主生成模型 | 即梦 / Seedance 2.0 | 其他模型为可替换次路径 |

用户指定时以用户为准，已有项目沿用已确认参数。新项目未指定画幅时默认 16:9，不因发布到抖音自动改为 9:16；其他未指定参数按上表执行。在 `00_立项.md` 记录画幅与分辨率，分镜构图、场景首尾帧、视频生成面板、提示词和剪辑导出统一使用该画幅。用户要求更换画幅时，同步重新构图，不只改导出尺寸。

## 生产目录

在项目根目录建 `漫剧/<剧名>/`，按阶段编号存放，便于回滚与交接：

```text
漫剧/<剧名>/
  00_立项.md            参数、风格、模型、发布计划
  01_选题与钩子.md      赛道、对标、标题、封面、前 15 秒
  02_集纲.md            全季分集表、伏笔表
  03_剧本/EP01.md       声画对位表
  04_角色/角色资产卡.md  身份锁定句、形态表、道具
  04_角色/参考图/       设定板与定妆图（外部生成）
  05_分镜/EP01.md       镜头表
  06_提示词/EP01.md     逐镜提示词与生成参数
  07_音频/EP01.md       配音清单、BGM 与音效表
  08_成片/EP01.mp4      剪辑导出（不入版本库）
```

已有项目沿用其目录，不另建平行结构。

## 工作流

### 第 1 步：选题与开头钩子

按 [topic-and-hook.md](references/topic-and-hook.md) 完成赛道判断、对标拆解和选题评分。

动作：

1. 拆 10–20 条同赛道对标，记录前 3 秒画面、首集爽点时间、集数、评论高频词。
2. 输出三个故事引擎不同的候选：稳健、差异化、低成本。
3. 用六维评分表打分，总分低于 24 分（满分 30）的不进入制作。
4. 定主标题、封面大字、前 3 秒画面 + 第一句台词。

交付物：`01_选题与钩子.md`。

通过标准：30 字内能说清「谁、遇到什么、要干什么、有什么不一样」；前 3 秒有画面奇观或直接冲突，没有背景铺陈。

### 第 2 步：集纲与单集结构

按 [series-structure.md](references/series-structure.md) 拆分全季与单集。

动作：

1. 用七拍结构排单集，标注每拍起止秒数。
2. 定前三集任务、每 3 集小高潮、季中大转折、季终钩。
3. 每集写「目标 / 阻力 / 爽点 / 结尾钩 / 新角色或新形态」，并核对伏笔表。

交付物：`02_集纲.md`。

通过标准：每集结尾都有未完成动作或新信息；连续两集不重复同一爽点类型；单集场景数 ≤ 5。

### 第 3 步：剧本改写为声画对位

按 [script-to-screen.md](references/script-to-screen.md) 把小说或梗概改写成可拍摄的声画对位表。

动作：

1. 拆三层：原文 → 口播稿（旁白 + 台词）→ 声画对位表（画面 / 声音 / 字幕）。
2. 每句台词独立成行，标注秒数与字数，控制在语速上限内。
3. 心理描写外化为动作或一句旁白；环境描写压成一个定场镜头。

交付物：`03_剧本/EP01.md`。

通过标准：旁白不复述画面；单句台词 ≤ 18 字；旁白与台词总字数 ≤ 时长 × 4.5 × 0.8。

### 第 4 步：角色资产与跨镜一致性

按 [character-consistency.md](references/character-consistency.md) 建档。

动作：

1. 写角色资产卡：物种、体型、毛色或甲壳纹理、眼睛、配饰、服装、伤疤、武器、进化阶段、声线。
2. 先出设定板（正面全身 / 3/4 侧 / 背面 / 面部特写 / 4 个表情），再出定妆图。
3. 为每个角色提炼 ≤ 40 字的身份锁定句，此后每个镜头原样复用。
4. 为进化或重生题材建形态表，每次变化只改一个识别特征，保留一个锚点特征。

交付物：`04_角色/角色资产卡.md` 与参考图。

通过标准：任意两镜并排，脸型、主色、配饰左右位置、体型比例一致；每个形态能被单独认出属于同一角色。

### 第 5 步：横竖屏分镜

按 [storyboard.md](references/storyboard.md) 出镜头表。

动作：

1. 每个镜头只写一个动作、一种运镜，标清景别、时长、画面、台词、音效。
2. 按项目画幅构图：16:9 利用横向空间、双人站位与视线留白；9:16 利用纵向层次与主体集中。按该画幅预留字幕和平台 UI 安全区。
3. 钩子段 0.6–1.2 秒/镜，对话 1.5–2.5 秒，情绪 2–3 秒，定场 2–3 秒。
4. 用 `scripts/timeline.py` 校验总时长与台词字数。

交付物：`05_分镜/EP01.md`（可附 CSV）。

通过标准：镜头时长合计等于目标时长（误差 ≤ 0.5 秒）；无连续 3 镜同景别；每个爽点至少有一个特写或大特写。

### 第 6 步：逐镜视频提示词

按 [shot-prompts.md](references/shot-prompts.md) 生成，主路径为即梦 / Seedance 2.0。

动作：

1. 按固定骨架写：风格 / 画幅 / 主体 / 构图 / 动作 / 环境 / 光影 / 运镜 / 时长 / 声音 / 约束 / 参考图；每条只写项目选定的一种画幅。
2. 单段 4–15 秒，提示词 ≤ 2000 字；单动作镜头控制在 150–300 字，信息密度优先。
3. 角色身份锁定句原样复用，参考图在提示词中写明用途。
4. 口型难对齐时改侧脸、背身、遮挡或后期配音，不强行写对口型。
5. 关键动作才用首尾帧法；普通叙事镜头用单段生成。

交付物：`06_提示词/EP01.md`，每镜含参数（时长、比例、参考图、模型）。

通过标准：每条提示词可单独粘贴生成；无文学描写、无负面词堆砌；镜头内动作不超过 3 个连续小动作。

### 第 7 步：配音与配乐

按 [audio-and-music.md](references/audio-and-music.md) 制作声音。

动作：

1. 先出 3 条试音（平静叙述 / 情绪爆发 / 反派），定声线与语速。
2. TTS 按句生成，逐句标情绪与停顿，避免整段长文一次性合成。
3. BGM 按情绪曲线切 2–3 段，卡点对齐爽点与集尾钩。
4. 音效只保留转场、打击、升级、环境和必要 UI 音。

交付物：`07_音频/EP01.md` 与音频文件。

通过标准：人声清晰领先，BGM 低于人声 12–18 dB；无一句台词被音效盖住；情绪变化至少有音乐或音效提示。

### 第 8 步：剪辑与成片

按 [edit-and-delivery.md](references/edit-and-delivery.md) 完成剪辑与发布物料。

动作：

1. 按分镜表粗剪 → 去空镜 → 铺音效与 BGM → 上字幕 → 统一调色 → 出封面。
2. 每 2–3 秒必须有画面变化；前 3 秒不放开场空镜或 Logo。
3. 按项目画幅导出：16:9 为 1920×1080，9:16 为 1080×1920；统一 30fps、H.264、8–12 Mbps、AAC 192 kbps。
4. 同步准备标题、封面字、3–5 个话题、合集与置顶评论。

交付物：`08_成片/EP01.mp4` 与发布信息。

通过标准：静音观看也能看懂主线；字幕不挡脸；封面大字 4–8 字在目标平台缩略图中清晰可读。

### 第 9 步：发布与复盘

1. 发布前按检查清单核对合规、AI 生成标识、字幕错别字、音画同步。
2. 记录 3 秒留存、完播率、追更评论关键词，按单集归因。
3. 只改一个变量（钩子 / 节奏 / 角色 / 标题）做下一集对照，不整套推翻。

## 关键换算

| 项目 | 公式 | 示例 |
| --- | --- | --- |
| 单集镜头数 | 时长 ÷ 平均镜长 | 75 ÷ 2.7 ≈ 28 镜 |
| 台词字数上限 | 秒数 × 4.5 | 8 秒 ≈ 36 字 |
| 实际口播字数 | 秒数 × 4.5 × 0.8（留停顿） | 75 秒 ≈ 270 字 |
| 单镜提示词时长 | 4–15 秒整数 | 长动作拆成两段 |
| 单集场景数 | 3–5 个 | 超 5 个合并同类场景 |
| 单集新增角色 | 0–1 个 | 首集可 2 个（主角 + 对手） |

字数统计口径：中文按汉字计，标点不计，英文单词按 1 字计。

## 单集验收清单

- [ ] 前 3 秒有画面钩子或直接冲突，无背景介绍。
- [ ] 25 秒内出现第一次爽点或强反转。
- [ ] 每 10 秒有信息变化，无连续 5 秒静止画面。
- [ ] 台词单句 ≤ 18 字，无书面语堆砌。
- [ ] 角色跨镜一致：脸、主色、配饰、体型、光源方向。
- [ ] 镜头时长合计与目标误差 ≤ 0.5 秒。
- [ ] 每个爽点有特写或大特写，配乐或音效同步强化。
- [ ] 结尾有未完成动作或新信息，形成追更钩。
- [ ] 立项选定的画幅全程统一，未指定时默认 16:9；字幕与标题不挡关键信息。
- [ ] 合规复核完成，AI 生成标识按平台当期要求处理。

## 常见失败与修复

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 3 秒跳出高 | 开头讲设定、放空镜 | 改成奇观、危机或反差开场，第一句台词即冲突 |
| 完播低 | 中段解释过多、镜头太长 | 删解释性旁白，镜长压到 2.5 秒内 |
| 角色换脸 | 每镜重写描述、参考图不稳定 | 固定身份锁定句 + 同一组参考图 + 首帧接力 |
| 画面像 PPT | 全片一个景别、无运镜 | 每 3 镜至少换一次景别，爽点加推镜或环绕 |
| 台词赶 | 字数超语速上限 | 按 4.5 字/秒重算，砍修饰词或拆镜 |
| 情绪不到位 | 只靠 BGM 撑 | 补动作外化、特写、音效与台词停顿 |
| 生成动作崩坏 | 一镜多动作、多人交互 | 拆成 2–3 镜，每镜一个连续小动作 |
| 集间断裂 | 无伏笔表、结尾无钩 | 建连续性表，每集结尾留新信息 |

## 时长与字数校验脚本

分镜排期与字数预算用脚本算，不靠估：

```bash
python scripts/timeline.py plan --duration 75 --shots 28 --cps 4.5
python scripts/timeline.py check --csv 05_分镜/EP01.csv --duration 75 --cps 4.5
```

`plan` 输出每镜起止秒数与台词字数上限；`check` 校验镜头总时长和每镜字数是否超速。CSV 表头固定为 `shot,duration,chars`。权重可用 `--weights` 传入逗号分隔数字，长度需与镜头数一致；不传则平均分配。
