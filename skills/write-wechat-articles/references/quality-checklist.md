# 发布前检查

完成初稿后检查一次，压缩后再检查一次。最多两轮。

## 技术与事实

- [ ] 版本、模型、平台、API、参数和命令有可靠依据
- [ ] 代码、提示词和预期结果自洽
- [ ] 已测试、资料整理、建议尝试和作者判断已区分
- [ ] 没有虚构数据、结果、经历、引用或用户反馈
- [ ] 参考资料直接支持正文关键结论

## 内容效率

- [ ] 开头快速进入问题或结论
- [ ] 文章只围绕一个核心问题
- [ ] 每段只表达一个重点
- [ ] 已删除重复结论、空泛铺垫和常识性展开
- [ ] 结尾没有重复全文
- [ ] 没有为了篇幅增加背景和术语

## 类型闭环

- [ ] 教程可以按步骤完成目标，并说明高频失败原因
- [ ] 原理分析讲清关键机制和边界
- [ ] 故障复盘覆盖证据、根因、修复和预防
- [ ] 评测说明测试条件、成本及适用范围
- [ ] AI 创作实践给出工作流、关键设置、完整提示词和限制
- [ ] 提示词分享标明工具、模型、完整提示词和可替换变量

只检查当前文章对应的类型。

## 公众号排版

- [ ] 标题少而明确，段落适合手机阅读
- [ ] 代码块和提示词块完整且不过度冗长
- [ ] 没有连续加粗、密集列表或装饰性符号
- [ ] `wechat.md` 只有简短说明和一个完整 `html` 代码块
- [ ] `wechat.md` 与 `wechat.html` 使用相同文章 HTML 片段
- [ ] 文章正文样式全部使用行内 CSS，不依赖外部资源
- [ ] 复制范围不包含按钮、说明、状态、页面背景或 `<h1>` 标题
- [ ] 富文本复制不可用时有兼容复制和手动复制提示
- [ ] HTML 特殊字符已转义，代码长行不会造成横向溢出
- [ ] Markdown 原稿与文章 HTML 内容一致
- [ ] 标题、摘要、封面提示词和互动语与正文一致

## 设计质量

- [ ] 全文只有一个强调色 `#246ba5`，无渐变、阴影或第二个强调色
- [ ] 全文统一 `6px` 圆角，无混用
- [ ] 无 AI 紫色光效、虚假截图或装饰性渐变
- [ ] 无装饰性圆点、版本标签或滚动提示
- [ ] 表格仅用于结构化对比，不超过 5 行
- [ ] 无破折号（—）作为装饰或分隔
- [ ] 无填充动词（彻底讲透、赋能、颠覆、一站式、无缝衔接）
- [ ] 所有数字有可靠依据，无虚假精确指标
- [ ] 非代码组件无背景色，深色主题下可读
- [ ] 完稿后已逐句重读所有可见文字

## 图片

- [ ] 每张图片都有解释、证明或比较作用
- [ ] 四个输出文件中的图片占位与配图清单编号、位置一致
- [ ] 截图、对比图和生成结果来自真实素材
- [ ] 网络图片已提示来源与授权风险
- [ ] 没有必要配图时已省略占位和清单

## 保存

- [ ] 已在当前工作区的 `微信公众号文章/` 下创建日期与短标题目录
- [ ] `article.md`、`wechat.md`、`wechat.html` 和 `assets.md` 职责清楚、内容完整
- [ ] `wechat.html` 可独立打开，不依赖网络资源
- [ ] 模板中的 `{{ARTICLE_HTML}}` 已完整替换
- [ ] 目录名已清理不安全字符并限制长度
- [ ] 同名目录已追加数字后缀，没有覆盖旧文章
- [ ] 无正文配图时，`assets.md` 仍包含封面图提示词
- [ ] 保存成功后，对话只返回摘要、四个文件链接和校验结果
- [ ] 保存失败时没有写入 Skill 安装目录，并已回退到完整对话输出

## 文风与风险

- [ ] 表达像一线实践者，不像营销稿
- [ ] 没有 AI 腔、故作深刻或强行幽默
- [ ] 限制、适用边界和技术取舍明确
- [ ] 不使用破折号作为装饰性表达
- [ ] 已提示必要的版权、肖像、声音克隆、隐私或平台风险

若任何关键项无法通过，修正文稿。两轮后仍无法确认事实时，列出缺口并停止扩写。
