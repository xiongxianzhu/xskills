# 发布前检查

完成初稿后检查一次，自然化重写后对照一次。文风与事实检查合计最多两轮，不另加润色循环。

## 技术与事实

- [ ] 版本、模型、平台、API、参数和命令有可靠依据
- [ ] 代码、提示词和预期结果自洽
- [ ] 已测试、资料整理、建议尝试和作者判断已区分
- [ ] 没有虚构数据、结果、经历、引用或用户反馈
- [ ] 参考资料直接支持正文关键结论

## 内容效率

- [ ] 开头快速进入问题或结论
- [ ] 文章只围绕一个核心问题
- [ ] 每段只表达一个重点
- [ ] 已删除重复结论、空泛铺垫和常识性展开
- [ ] 结尾没有重复全文
- [ ] 没有为了篇幅增加背景和术语

## 类型闭环

- [ ] 教程可以按步骤完成目标，并说明高频失败原因
- [ ] 原理分析讲清关键机制和边界
- [ ] 故障复盘覆盖证据、根因、修复和预防
- [ ] 评测说明测试条件、成本及适用范围
- [ ] AI 创作实践给出工作流、关键设置、完整提示词和限制
- [ ] 提示词分享标明工具、模型、完整提示词和可替换变量

只检查当前文章对应的类型。

## 公众号排版

- [ ] 标题少而明确，段落适合手机阅读
- [ ] 代码块和提示词块完整且不过度冗长
- [ ] 没有连续加粗、密集列表或装饰性符号
- [ ] `wechat.md` 只有简短说明和一个完整 `html` 代码块
- [ ] `wechat.md` 与 `wechat.html` 使用相同文章 HTML 片段
- [ ] 文章正文样式全部使用行内 CSS，不依赖外部资源
- [ ] 复制范围不包含按钮、说明、状态、页面背景或 `<h1>` 标题
- [ ] 富文本复制不可用时有兼容复制和手动复制提示
- [ ] HTML 特殊字符只转义一次，代码文本与原文一致，标签合法闭合
- [ ] 单行代码和提示词不自动换行，多行保留原始行数、空行与缩进
- [ ] 长行仅在代码块内滚动，能够读到末尾；不截断、不缩字、不撑宽页面
- [ ] 不依靠预览页 CSS 或页面级隐藏溢出修补正文；滚动规则均在正文行内样式中
- [ ] Markdown 原稿与文章 HTML 内容一致
- [ ] 标题、摘要、封面提示词和互动语与正文一致

## 设计质量

- [ ] 已从 6 款预设选定一款，主题参数已按 [themes.md](themes.md) 展开且全文一致
- [ ] 主题强调色仅用于边线；链接下划线、字号及粗细在无色环境下仍能表达层级
- [ ] 代码块与提示词块圆角不超过 2px，图片占位使用所选主题圆角，无渐变、阴影或额外装饰色
- [ ] 无 AI 紫色光效、虚假截图或装饰性渐变
- [ ] 无装饰性圆点、版本标签或正文中的滚动提示文案
- [ ] 表格仅用于结构化对比，不超过 5 行
- [ ] 已去掉无信息价值的装饰性标点与套话，未误改作者样稿习惯、引文或技术内容
- [ ] 所有数字有可靠依据，无虚假精确指标
- [ ] 正文、标题、序号、链接、引用、图注和表格继承文字色，背景透明
- [ ] 代码文字、注释和高亮与代码底色对比度至少 4.5:1
- [ ] 每款使用的主题已检查 320px、375px、768px 下的浅色和深色预览，无页面横向溢出
- [ ] 切换预览环境不修改源文章 HTML；复制不带入预览文字色或页面底色
- [ ] 现代、兼容与手动复制路径不含标题、工具栏、说明或临时节点，代码文本完整
- [ ] 微信编辑器粘贴和手机深浅模式实测已单独记录；未执行时标明“微信真机待验证”
- [ ] 完稿后已逐句重读所有可见文字

## 图片

- [ ] 每张图片都有解释、证明或比较作用
- [ ] 四个输出文件中的图片占位与配图清单编号、位置一致
- [ ] 截图、对比图和生成结果来自真实素材
- [ ] 网络图片已提示来源与授权风险
- [ ] 没有必要配图时已省略占位和清单

## 保存

- [ ] 已在当前工作区的 `微信公众号文章/` 下创建日期与短标题目录
- [ ] `article.md`、`wechat.md`、`wechat.html` 和 `assets.md` 职责清楚、内容完整
- [ ] `wechat.html` 可独立打开，不依赖网络资源
- [ ] 文章中的主题参数和外壳中的 `{{ARTICLE_HTML}}` 已完整替换
- [ ] 目录名已清理不安全字符并限制长度
- [ ] 同名目录已追加数字后缀，没有覆盖旧文章
- [ ] 无正文配图时，`assets.md` 仍包含封面图提示词
- [ ] 保存成功后，对话只返回摘要、四个文件链接和校验结果
- [ ] 保存失败时没有写入 Skill 安装目录，并已回退到完整对话输出

## 文风与风险

- [ ] 按 [natural-writing.md](natural-writing.md) 自检，默认专业自然；有作者样稿时已匹配文风且未移植其中的事实
- [ ] 段落写清具体主体、动作、结果或取舍，未用形容词和空泛意义代替信息
- [ ] 无机械三点式、重复预告、标题复述或连串碎句，必要的步骤和结构化列表保留
- [ ] 未新增作者经历、感受、实测或权威来源，真实细节与有依据的判断已保留
- [ ] 重写前后数值、版本、范围、条件、否定与确定程度一致，必要的不确定性未被删除
- [ ] 代码、命令、配置、完整提示词、引文原话、引用标识和链接目标未因文风润色而改变
- [ ] 结尾提供最后一个有用信息，未强加总结、升华、泛泛问题或聊天式服务用语
- [ ] 仅交付最终成稿，没有中间稿、AI 痕迹分析、检测分数或保证通过检测的说法
- [ ] 限制、适用边界和技术取舍明确
- [ ] 已提示必要的版权、肖像、声音克隆、隐私或平台风险

若任何关键项无法通过，修正文稿。两轮后仍无法确认事实时，列出缺口并停止扩写。
