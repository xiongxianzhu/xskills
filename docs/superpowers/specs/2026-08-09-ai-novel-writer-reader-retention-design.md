# ai-novel-writer 网文追读能力重构设计

## 1. 背景与目标

`ai-novel-writer` 当前能够创建作品目录、维护设定与连续性，并生成独立的漫剧改编资料，但主要解决的是交付结构和改编衔接问题。现有规则缺少对点击、前 300 字、前三章冷启动、期待与兑现、差异化故事引擎的系统约束；现有评测也主要检查文件是否齐全，难以判断正文是否真正具有追读力。

本次重构面向番茄、红果一类免费网文阅读场景，同时覆盖男频和女频。最高目标是提高读者的点击、读完与继续追更意愿；采用成熟商业节奏，但通过人物利益、冲突方式与机制代价保持原创性。漫剧适配保留为次级能力，不得反向损害小说的阅读体验。

## 2. 成功标准

重构后的 Skill 应当做到：

- 书名与简介能呈现明确的类型承诺、主角困境和差异点。
- 前 300 字建立主角、即时问题以及核心卖点的证据或明确逼近。
- 前三章完成“承诺启动、机制验证、首次兑现”的冷启动闭环。
- 每章处理至少一项已有期待，并提供信息、能力、情绪、关系、资源或危机解除中的至少一种有效收益。
- 男频与女频共用留存机制，但使用不同的阅读收益模型。
- 熟悉题材至少通过两个进入实际情节的变量实现差异化，而不是只换职业、姓名或能力外观。
- 续写能够读取期待状态，合理兑现、升级或延迟旧期待，而不是不断增加新谜团。
- 正文优先保证人物逻辑、因果和沉浸感；漫剧限制只进入独立交接资料。
- 确定性检查可以发现字数、缺失文件、空白字段、编号、链接和资料同步错误。
- 内容评审必须引用正文证据，不能用大纲中的自我声明代替质量判断。

## 3. 非目标

本次不负责：

- 将小说直接转换为逐镜头分镜、图像提示词或视频提示词。
- 模仿在世作者的独特文风。
- 用固定句式、固定反转位置或统一节拍模板生产所有题材。
- 为每章生成多份完整正文并无限比较。
- 为旧作品强制重命名文件或迁移目录。
- 把平台经验包装成确定的真实留存率预测。

## 4. 决策优先级

规则发生冲突时，按以下顺序处理：

1. 读者能否理解并愿意继续阅读。
2. 人物行为与故事因果是否成立。
3. 商业节奏以及情绪或爽点兑现。
4. 题材与人物是否具有差异化。
5. 是否方便改编为漫剧。
6. 是否节省漫剧制作成本。

因此，“一章一集”、固定场景数量和视觉资产复用不再约束小说正文，只影响正文完成后的漫剧改编资料。

## 5. 总体架构

执行链路如下：

```text
用户需求
→ 作品定位
→ 留存核心
→ 男频或女频主策略
→ 正文生成与质量审判
→ 状态和期待更新
→ 漫剧适配资料
```

`SKILL.md` 只负责：

- 判断新建、续写或修改任务。
- 提取用户已给出的信息，只询问会显著改变方向的关键缺口。
- 识别男频或女频主策略，并选择所需参考文件。
- 创建、读取和维护作品文件。
- 控制“策划、写作、审判、局部重写、更新资料、生成改编交接”的顺序。
- 处理已有文件、资料冲突和连续性安全。

具体写作机制拆分到以下参考文件：

```text
references/
├── retention-core.md
├── male-oriented.md
├── female-oriented.md
├── innovative-short-story.md
├── originality-control.md
├── quality-review.md
└── manju-adaptation.md
```

- `retention-core.md`：点击、前 300 字、前三章、期待与兑现、单章追读。
- `male-oriented.md`：男频获得感、目标升级、资源变化和有效对抗。
- `female-oriented.md`：女频情绪价值、关系权力变化和人物选择。
- `innovative-short-story.md`：短篇篇幅与结构策略，可与男频或女频策略组合，不再互斥。
- `originality-control.md`：熟悉承诺、差异化变量、故事引擎和同质化审判。
- `quality-review.md`：阅读检查点、硬性失败项、分维度诊断和最小重写。
- `manju-adaptation.md`：正文完成后的独立改编交接，不参与正文节奏决策。

## 6. 追读机制

### 6.1 点击层

新建作品时为“书名、简介、开篇切入点”生成三个轻量候选组合，比较后选择一个。候选比较检查：

- 能否识别题材或核心异常。
- 简介前两句是否出现主角困境与独特机制。
- 是否承诺明确的情绪收益、获得感或成长方向。
- 是否存在至少一个同类作品中可辨认的差异点。
- 是否避免用世界观、身份标签和空泛形容代替事件。

候选竞争只用于上述高杠杆入口，不扩展为每章多版本正文。

### 6.2 前 300 字

前 300 字至少完成以下三项：

- 明确读者正在关注的人物。
- 展示异常、利益、危机或关系裂痕。
- 让主角面对必须立即处理的问题。
- 给出核心机制的证据或明确逼近。
- 建立一个具体且有代价的疑问。

履历、世界观说明、天气空镜和无关日常不得占据开篇。环境描写只有同时制造压力、信息或人物判断时才保留。

### 6.3 前三章冷启动

前三章采用功能约束，不采用固定剧情公式：

- 第一章“承诺启动”：建立不可忽略的困境，露出核心机制，主角主动选择，章末改变行动方向。
- 第二章“机制验证”：主角主动试探，获得真实收益或情绪反馈，同时暴露限制、代价或更强阻力。
- 第三章“首次兑现”：男频获得阶段成果；女频产生可感的关系、边界、权力或自我选择变化；结尾打开第一个中期目标。

前三章结束后，读者应能回答：作品以后主要看什么、主角为何值得跟随、下一阶段期待什么。

### 6.4 四层期待

每部作品同时维护四类期待：

- 即时期待：下一场戏将如何变化。
- 章节期待：当前目标能否完成。
- 阶段期待：主角何时反击、揭密、升级或改变关系。
- 长线期待：身份、终局、核心秘密或最终关系。

每章至少对一项已有期待进行兑现、部分兑现、升级，或在提供新证据后合理延迟。禁止连续只新增谜团而不回答旧问题。

### 6.5 单章闭环

写作前定义：

- 本章读者最想看到的结果。
- 本章必须提供的阅读收益。
- 阻止结果轻易发生的有效阻力。
- 主角必须做出的选择。
- 结尾产生的不可逆变化。

章末可以采用决策钩、后果钩、信息钩、关系钩或目标钩，但必须来自本章因果。与本章无关的车祸、神秘电话、突然昏迷等事故不得作为廉价截断。

每章必须提供信息、能力、情绪、关系、地位、资源、局势掌控或危机解除中的至少一种有效收益。连续两章没有有效收益，判为高流失风险。

## 7. 男女频策略

### 7.1 路由

优先使用用户明确指定的男频或女频方向。用户未指定时，根据主要阅读收益判断：

- 升级、掌控、解谜、事业、竞争或守护为主，采用男频主策略。
- 关系变化、情感选择、自我价值、身份处境或生活重建为主，采用女频主策略。

混合题材只选择一个主策略，另一类作为副线。仅在判断会明显改变作品方向且无法从上下文推断时询问用户。

### 7.2 男频引擎

男频策划必须明确当前困局、阶段目标、核心优势、能力限制、使用代价、有效对手和成果转化。阶段循环为：

```text
读者预期成果
→ 主角判断并行动
→ 有效对手反制
→ 主角承担代价或暴露限制
→ 依靠已建立的能力与选择破局
→ 获得可感成果
→ 成果带来更高层的新问题
```

成果应转化为资源、身份、地位、认知或保护能力。禁止用围观者震惊、反派降智和重复打脸替代获得感。

### 7.3 女频引擎

女频策划必须明确女主处境、外部目标、内部需要、错误认知，以及关系双方的目标、筹码、底线与选择权。阶段循环为：

```text
关系或处境失衡
→ 人物因现实目标发生互动
→ 暴露新的立场或脆弱点
→ 信任、边界或权力发生变化
→ 人物做出有代价的选择
→ 产生甜、虐、爽或成长兑现
→ 新状态制造下一阶段问题
```

禁止依靠长期拒绝沟通、无条件原谅伤害和配角集体工具化维持剧情。

## 8. 原创性控制

原创性采用“一个熟悉承诺 + 至少两个差异化变量”。可选变量包括：

- 主角职业或解决问题的方法。
- 核心能力的使用方式、限制与代价。
- 冲突发生的社会空间。
- 主角与关键人物的利益关系。
- 获胜或情绪兑现的代价。
- 对手的合理立场与反制方式。
- 叙事信息差。
- 稳定意象或语言气质。

差异化变量必须进入实际冲突，不能只写在设定表。策划完成后检查：

- 换掉姓名和职业后，作品是否立即退化为常见模板。
- 能力或关系设定是否既提供优势，也制造独特代价。
- 三个主要冲突是否采用不同的解决逻辑。
- 重要配角是否拥有主角不在场时仍会推进的目标。

检查失败时，只重做故事引擎与人物利益关系，不通过增加无关世界观设定掩盖问题。

## 9. 作品文件模型

新作品采用：

```text
小说/作品名/
├── 00_作品定位.md
├── 01_角色设定.md
├── 02_故事总纲.md
├── 03_章节规划.md
├── 04_创作进度.md
├── 05_追读账本.md
├── 正文/
└── 漫剧改编/
```

### 9.1 文件职责

- `00_作品定位.md`：平台、受众、主策略、类型承诺、核心快感、故事引擎、熟悉点、差异点、基调、视角与内容边界。
- `01_角色设定.md`：欲望、需要、读者站位、筹码、能力、缺陷、代价、底线、典型选择、利益冲突、独立行动线、语言行为特征及视觉锚点。
- `02_故事总纲.md`：开局困境、前三章冷启动、阶段期待、阶段目标、阻力、中点变化、阶段兑现、新局面、高潮、结局及伏笔范围。
- `03_章节规划.md`：开书时详细规划前三章，概略规划前十章；之后滚动维护。每章记录期待、目标、阻力、选择、兑现、不可逆变化、章末问题与所处理的期待条目。
- `04_创作进度.md`：只维护已完成章节、时间地点、人物状态、关系资源能力变化、不可撤销事实、伏笔和下一章承接事实。
- `05_追读账本.md`：维护活跃期待的类型、建立章节、预计兑现区间、证据、兑现程度、延迟理由、热度、连续未处理章数和下一步动作；同时记录近期章节的收益类型。

章节长度由内容功能和用户要求决定，不再为“一章一集”机械限定。用户没有指定时，可给出平台适宜区间并允许自然浮动。

### 9.2 旧作品兼容

- 识别旧版 `00_作品设定.md` 和 `03_分集大纲.md`。
- 不强制重命名或重建已有文件。
- 从现有设定、大纲、进度和正文推导缺失的 `05_追读账本.md`。
- 只有用户明确要求迁移时才调整旧目录结构。
- 不覆盖已有章节或无关内容。

### 9.3 数据流

```text
作品定位决定读者承诺
→ 角色设定提供行动与冲突来源
→ 故事总纲安排阶段期待和兑现
→ 章节规划决定本章功能
→ 正文落实场景、行动与情绪
→ 质量审判发现流失点并局部修正
→ 创作进度记录事实
→ 追读账本更新期待状态
→ 生成独立漫剧资料
```

## 10. 质量审判与重写

### 10.1 三个阅读检查点

正文完成后检查：

- 前 300 字：主角、当前问题、核心看点和可删除的无效背景。
- 章节中段：主角是否行动、阻力是否改变局势、是否出现新信息或收益、场景是否重复。
- 章节结尾：承诺是否至少部分兑现、结尾是否来自因果、局面是否不可逆变化、下一章期待是否具体。

### 10.2 硬性失败项

出现以下任意情况必须修改：

- 前 300 字仍不知道主角当前问题。
- 核心卖点只存在于设定文件，正文没有证据。
- 主角整章没有主动选择。
- 冲突依赖人物明显降智。
- 本章没有任何有效收益。
- 结尾钩子与本章因果无关。
- 人物行为违反已建立的欲望、底线或能力边界。
- 为制造原创感突然增加无铺垫设定。
- 只增加悬念，没有处理旧期待。
- 正文字数明显偏离用户要求。

### 10.3 分维度诊断

分别判断进入速度、读者站位、卖点证据、冲突质量、收益兑现、差异化、章末追读和语言沉浸为“强、可用、弱”。弱项必须指出具体位置与原因，不得只写“节奏不够快”或“增强冲突”。

### 10.4 最小重写

- 开篇无效：重写前 300 字。
- 主角站位不足：补强具体损失、欲望或选择。
- 卖点过晚：前移第一次机制证据。
- 中段松散：合并重复场景并提前阻力。
- 兑现不足：补足行动结果，不新增无关事故。
- 钩子生硬：让结尾由本章选择产生。
- 同质化：调整利益关系或解决方式。
- 对话通用：强化立场、目的和隐瞒信息。

除非故事引擎本身失效，否则不得整章推倒重写。审判只检查功能，不强制固定句式、段落数和节拍位置。

## 11. 异常处理

- 设定文件相互矛盾：停止扩大矛盾，指出冲突并给出最小修正方案。
- 大纲与人物动机冲突：优先保留人物逻辑，再调整情节。
- 留存规则与因果冲突：优先保证因果，通过提前铺垫或更换钩子解决。
- 阅读体验与漫剧成本冲突：保留正文，在改编资料中提出压缩方案。
- 用户要求模仿在世作者：提炼高层风格特征，不复制独特文风。
- 用户允许自主创作且资料不足：合理补全，并把会影响后续的关键假设写入作品定位。
- 文件已存在：除非用户明确要求修改，否则不直接覆盖。

## 12. 评测设计

### 12.1 确定性检查

检查：

- 必要作品文件是否齐全。
- 章节编号是否连续。
- 正文与改编资料是否分离。
- 正文字数是否满足用户要求及允许误差。
- 正文是否混入镜头编号、提示词或制作说明。
- 追读账本是否包含活跃期待和处理状态。
- 创作进度是否同步更新。
- 是否残留 `TODO`、`TBD` 或空白模板字段。
- 新增链接是否指向存在的文件。

### 12.2 内容质量评审

评审必须从产物中引用证据，检查：

- 点击理由：书名与简介是否呈现承诺和差异点。
- 前 300 字：是否建立主角、问题与卖点证据。
- 主角站位：是否存在具体欲望、损失、底线或主动选择。
- 故事引擎：核心机制能否产生至少三种不同冲突。
- 首章兑现：是否提供至少一种明确阅读收益。
- 章末追读：是否形成因果产生的具体期待。
- 男女频适配：阅读收益是否符合主策略。
- 原创性：至少两个差异化变量是否进入实际情节。
- 人物逻辑：行为是否符合欲望、筹码和能力边界。
- 语言表现：具体场景是否多于抽象总结，是否避免模板句堆叠。

### 12.3 评测场景

至少覆盖：

1. 男频新建作品：能力边界、首次能力证明、获得感和长期引擎。
2. 女频新建作品：关系双方目标、选择权变化、情绪兑现和配角独立性。
3. 弱创意补强：从常见梗生成差异化冲突，而不是套路换皮。
4. 既有作品续写：读取追读账本，兑现旧期待并保持连续性。
5. 低质量开篇修改：诊断背景堆积和主角被动，只改必要部分。
6. 小说与漫剧冲突：保留阅读体验，在改编资料中提出压缩方式。

### 12.4 样例升级

将《雾港修表人》补成合格基准：

- 首章达到目标字数。
- 前 300 字建立主角、失踪妹妹、异常怀表和行动问题。
- 增加主动试探、有效受阻和真实信息收益。
