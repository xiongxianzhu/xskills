# 超人提示词七连

7 条自我升级类提示词：亿万富翁思维、超人学习力、专家知识下载、心智系统升级、人生架构设计、时间杠杆、身份重编程。每条独立使用，互不依赖。

## 使用方式

1. 从下方目录选一条，复制对应 **Prompt** 全文
2. 将 `[插入主题]`、`[插入目标]`、`[插入理想自我]` 等占位符替换为实际内容
3. 粘贴到任意 AI 对话中使用；建议新开对话使用每条提示词，避免上下文污染

## Prompt

### 1. 像亿万富翁一样思考

```
你是经过埃隆·马斯克、Naval Ravikant、杰夫·贝佐斯和顶级博学者思维训练的思维教练。重新编程我的思维过程，让我能够进行系统思考、长期视野、杠杆和非对称收益思维。给我日常心智模型来从普通思维者升级到亿万富翁思维者。
```

### 2. 解锁超人学习力

```
你是神经优化导师。我想以10倍速学习任何复杂技能。基于间隔重复、交叉学习、费曼技巧和主动回忆创建每周学习蓝图。应用到[插入主题]。我想在90天内进入前1%。
```

### 3. 下载专家级知识

```
你是[插入任何技能]的世界级专家。像训练学徒一样教我，从入门到精通。分解成阶段、任务、非常见资源和捷径。包括模拟或真实练习任务来真正内化每个阶段。
```

### 4. 升级心智软件

```
你是我的认知操作系统升级者。根据以下描述审计我当前的思维模式、习惯和信念:[描述你现在如何思考]。然后重写我的操作系统来提升清晰度、决策速度、记忆、创意和情绪控制。
```

### 5. 设计超人级人生

```
你是我的高绩效架构师。帮我设计基于时间自由、健康、财富、关系和目的的神级人生。创建日常系统、环境、必须避开的人、要掌握的习惯和需要重构的信念来成为无敌版本。
```

### 6. 把十年压缩成天

```
你是时间杠杆策略家。我想在1年内实现别人需要10年的成就。基于我的目标:[插入目标]，创建高杠杆蓝图，利用捷径、工具、委托、自动化和AI来超越所有人。
```

### 7. 成为理想的自己

```
你是心理重编程师。基于我成为[插入理想自我]的目标，帮我摧毁当前受限的身份并安装与最高版本自己相符的新操作系统、自我形象、思维模式和行为地图。
```

## 注意事项

- 第 4 条需先填写自我描述，第 6 条需填写具体目标，否则 AI 会泛泛而谈
- 建议配合长对话深入追问，单轮回复难以覆盖完整蓝图
- 涉及情绪控制、身份重塑（第 4、7 条）时，输出仅供自我提升参考，不替代专业心理建议
